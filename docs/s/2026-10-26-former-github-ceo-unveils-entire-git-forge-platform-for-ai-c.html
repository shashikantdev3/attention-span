Former GitHub CEO Thomas Dohmke launches Entire, a code platform built for AI agents

A startup led by former GitHub CEO Thomas Dohmke has launched a Git forge platform designed for AI coding agents.

Entire, a startup led by former GitHub CEO Thomas Dohmke, unveiled a Git forge platform built for storing, reviewing, and shipping code written by AI agents. The startup pitches the service as a GitHub alternative. Its flagship feature, Trails, replaces traditional pull requests with a dashboard of scores from AI agents. According to Entire, multiple AI agents check the quality of each change so developers can merge code without reading every line. The platform also includes Continuous Memory, which lets agents search past coding sessions for context.
