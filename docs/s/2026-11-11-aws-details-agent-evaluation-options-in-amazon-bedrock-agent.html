AWS details agent evaluation options in Amazon Bedrock AgentCore Evaluations

AWS explains how to evaluate production agents on Amazon Bedrock AgentCore using built-in, DeepEval and AutoEval evaluators, starting from business outcomes rather than metric names.

An AWS Machine Learning Blog post lays out how to evaluate agents on Amazon Bedrock AgentCore. It says teams should define success in business terms, break it into observable behaviors, and map each behavior to an evaluator at trace or session level. AgentCore offers three evaluator sources. Built-in evaluators are authored and quality-tested by AWS, referenced by ID such as Builtin.GoalSuccessRate. Third-party managed evaluators come from DeepEval and AutoEval, with AgentCore hosting the code and running inference. Custom evaluators start from a built-in or third-party one, so you can swap in your own model and change the prompt or rubric.

Like I am 5

Checking an AI helper is like checking a kid's homework. You don't just see that they finished. You check each part, like whether they got the answers right and followed the steps.

Why it matters

Teams running agents in production can score task completion, tool use and safety separately, so a high score on one measure cannot hide a failure on another.
