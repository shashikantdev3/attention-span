Wiz Research Reports Critical PHP RCE Vulnerabilities Discovered with AI

Wiz Research used frontier AI models to uncover critical memory-safety and remote code execution vulnerabilities in core PHP.

Wiz Research uncovered multiple critical memory-safety and unauthenticated remote code execution vulnerabilities in core PHP. PHP powers 70 percent of all websites in the world, including WordPress, Joomla, Drupal, and Wikipedia. Every PHP version released in the last decade, going back to version 5.4, is affected. Frontier AI models helped researchers chain multiple flaws and develop working exploits across multiple applications in hours. The underlying issues stem from how PHP handles fatal errors. PHP released a patch fixing these vulnerabilities on October 21, 2026.
