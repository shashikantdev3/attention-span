llama.cpp reaches v1.0.0 and ties API and ABI breaks to major versions

llama.cpp and ggml released v1.0.0 libraries, and API and ABI incompatibilities will now be reflected in major-version bumps.

The llama.cpp team at Hugging Face released v1.0.0 of its libraries, 3.5 years after the project began. Both llama.cpp and ggml will now reflect API and ABI incompatibilities with major-version bumps. The team says many downstream applications depend on its work. It is investing in CI infrastructure, using HF Buckets and HF Jobs, with hardware support from NVIDIA, AMD, Qualcomm, Arm, IBM and Intel for self-hosted runners. llama.cpp supports more than 150 architecture variants and all mainstream speculative decoding methods. Each ggml backend can be compiled as a dynamic library and optionally loaded at runtime.
