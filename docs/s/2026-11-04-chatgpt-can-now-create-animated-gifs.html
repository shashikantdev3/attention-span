ChatGPT Can Now Create Animated GIFs

OpenAI added animated GIF creation to ChatGPT alongside the Images 2.6 model update.

ChatGPT can now create animated GIFs using a prompt or an uploaded photo. The feature rolls out alongside OpenAI's new Images 2.6 model. Users can adjust the animation speed, edit individual frames, and share the GIFs. Before this update, ChatGPT could not natively generate GIFs in a single step. The Images 2.6 update also brings faster image generation to ChatGPT. OpenAI reports that users generate over 4 billion images per week across ChatGPT and its API. Additionally, OpenAI is launching GPT-Image-2.6 Flare and Sunburst in its API for faster and higher-quality image generation.

Why it matters

Users gain native support for generating and editing animated GIFs directly inside ChatGPT.
