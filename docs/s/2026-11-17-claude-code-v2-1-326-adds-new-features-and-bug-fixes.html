Claude Code v2.1.326 adds new features and bug fixes

Version 2.1.326 introduces support for Code Mode with agent teams, startup warnings, and various bug fixes.

Version 2.1.326 brings several updates. It adds support for turning on Code Mode while agent teams are enabled. Sessions with teams on now start in Code Mode. A startup warning appears when tool rules are incomplete. A new message explains why Model Context Protocol servers stop loading when an administrator adds managed-mcp.json. A row in /status shows when providers or environment variables turn features off. It also fixes numerous bugs, including issues with file copying under edit deny rules, Bash command transcripts, and background sessions losing LLM gateways.
