Anthropic launches Claude Ship, agents that review, fix and can approve GitHub pull requests

Claude Ship bundles Code Review with two beta agents, PR Steward and Claude Approvals, for Team and Enterprise customers.

Anthropic introduced Claude Ship, a set of agents for the last stage of software delivery on GitHub. It combines Code Review, which is generally available, with PR Steward, a beta agent that works on failing CI checks, merge conflicts and review feedback and explains each change, and Claude Approvals, a beta agent that approves routine pull requests according to a policy file the team writes in the repository. Anthropic recommends running Approvals in observe-only mode first, and existing branch protection still applies. Developers can also run a /ship command in Claude Code. It is available on Claude Team and Enterprise plans, billed on tokens with admin spend limits, and is not offered to organizations using zero data retention, the HIPAA configuration or customer-managed keys. Eligible Enterprise customers can claim at least $10,000 in credits until 15 January 2027.

Like I am 5

Claude can now check other programmers' code changes, fix small problems, and say 'this is OK to add' when the team's rules allow it.

Why it matters

Letting an agent approve merges under a written policy moves AI from writing code to gatekeeping it, which changes how teams set up code ownership, branch protection and audit.
