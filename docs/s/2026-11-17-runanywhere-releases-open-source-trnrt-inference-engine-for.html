RunAnywhere Releases Open-Source TrnRT Inference Engine for AWS Trainium

RunAnywhere launched TrnRT, an open-source inference engine for large language models on AWS Trainium, starting with GLM-5.3-Flash support.

RunAnywhere introduced TrnRT, an open-source LLM inference engine built for AWS Trainium hardware. The engine serves an OpenAI-compatible API from a trn2.48xlarge instance. It runs decode as Neuron Kernel Interface megakernels and keeps a prefix cache across device and host memory. GLM-5.3-Flash is the first supported model. Benchmarking on SemiAnalysis AgentX replays used a 1M-token context with concurrent agents. The project requires Neuron SDK 2.32 and Python 3.13, offering a Docker-based compile and serve workflow under the Apache License 2.0.
