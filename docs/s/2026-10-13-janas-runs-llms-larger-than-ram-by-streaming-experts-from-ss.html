Janas Runs LLMs Larger Than RAM by Streaming Experts from SSD

Janas-LLM runs large mixture-of-experts language models on ordinary computers by keeping weights on disk and streaming needed experts from an NVMe SSD.

Designed and written in C by Maurizio Cammalleri, Janas-LLM is an experimental tool that allows ordinary computers to run large mixture-of-experts language models that are larger than the available RAM. The engine keeps model weights on an NVMe SSD and streams required experts for each token into memory, while frequently used experts stay cached. Tested on a laptop with 32 GB of RAM and an Intel Core Ultra 9 processor, Janas-LLM successfully ran an 80-billion parameter model. It supports Linux and Windows operating systems.
