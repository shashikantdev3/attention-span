Gemini API adds file slicing so developers pay only for the pages, cells or clips a model reads

Google DeepMind's new server-side controls let the Gemini API load selected page ranges, spreadsheet cells or media segments instead of whole files.

Google introduced file slicing controls in the Gemini API that let developers ask the model to load only part of a file. For documents and slides that means page ranges, resolution and whether to use page text or page images; for spreadsheets a tab, cell range and layers such as data, formulas or visuals; for video time ranges, frame rate and transcript, frames or audio. Slicing happens on Google's side, so clients no longer need tools like LibreOffice or ffmpeg to cut files first. Developers pay only for the tokens the model inspects, and Google cites partners such as Vercel and LiteLLM reporting large token savings on PDFs and workbooks. The controls are available now in Google AI Studio and Vertex AI and work across all Gemini 4 models, Google says.
