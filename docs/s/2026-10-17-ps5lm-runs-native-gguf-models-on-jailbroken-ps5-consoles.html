PS5LM Runs Native GGUF Models on Jailbroken PS5 Consoles

PS5LM runs any GGUF language or decision model natively on the GPU of a jailbroken PlayStation 5 without using a PC.

PS5LM allows users to run language and decision models natively on the GPU of a jailbroken PlayStation 5. The app uses llama.cpp with a Vulkan backend on the console RDNA 2 GPU. It uses 11.4 GB of shared memory for the model and its context. The software serves OpenAI and Anthropic APIs over the network and streams requests and replies on the TV screen. It supports loading models from Hugging Face to internal, M.2, or USB storage. The system requires a jailbroken PS5 running firmware 7.00 to 13.60.

Why it matters

Running open weight models natively on video game consoles provides a local private model server without needing a separate PC or cloud account.
