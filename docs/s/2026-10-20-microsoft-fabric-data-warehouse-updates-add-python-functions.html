Microsoft Fabric Data Warehouse Updates Add Python Functions and Analytics

Microsoft Fabric Data Warehouse adds preview support for Python logic in T-SQL, four new language enhancements, and new analytical functions.

Microsoft Fabric Data Warehouse now integrates with Fabric User Data Functions in preview, allowing developers to extend T-SQL with custom Python logic. Users can invoke Python functions from standard statements like SELECT, INSERT, and UPDATE to send messages, access OneLake data, and retrieve secrets. Additionally, four T-SQL language enhancements are available in preview, including GROUP BY ALL, ORDER BY ALL, the QUALIFY clause, and the FROM ... SELECT query format to reduce repetitive code. The warehouse also added preview support for new analytical functions like MEDIAN, QUANTILE, APPROX_MEDIAN, and APPROX_QUANTILE.

You can now use a helper language to do special math and send messages right inside your main database commands, much like adding a special tool to your toy box to help you finish building blocks faster.

Why it matters

Extending T-SQL with custom Python logic and new analytical functions allows data teams to perform complex data transformations and external calls directly inside the warehouse.
