Google Adds File Generation and Editing to Gemini Chats

Google now lets users generate, preview, and edit files like Google Docs directly within Gemini chats.

Google has launched new file editing capabilities for all Gemini users. Users can now generate, preview, and edit PDFs, Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code directly within Google Gemini. PDF previews and editing work on both the web and mobile, while other file formats are currently limited to the web version. Users can expand documents into full-screen mode, highlight text to ask questions, or prompt Gemini to make changes. Anthropic launched a similar feature earlier this year in Claude chats.

Why it matters

Editing files directly inside chat interfaces reduces context switching during document creation workflows.
