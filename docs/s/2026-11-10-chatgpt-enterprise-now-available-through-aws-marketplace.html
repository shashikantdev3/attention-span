ChatGPT Enterprise now available through AWS Marketplace

OpenAI has made ChatGPT Enterprise available in AWS Marketplace, so organizations can buy it through their existing AWS purchasing and billing relationship.

ChatGPT Enterprise is now available through AWS Marketplace. Organizations can discover, buy and manage it using their existing AWS purchasing and billing relationship, and apply eligible spend toward their AWS commitments. AWS customers get the same models, features and functionality as buying directly from OpenAI, with new features released at the same time. The listing complements the OpenAI models in Amazon Bedrock, where developers can build AI applications and agents. Eligible customers can also access ChatGPT for Healthcare and ChatGPT for Financial Services through AWS Marketplace. Customers should contact their OpenAI or AWS account team to confirm eligibility.
