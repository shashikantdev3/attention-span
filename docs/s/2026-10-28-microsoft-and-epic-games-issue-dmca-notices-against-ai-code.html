Microsoft and Epic Games Issue DMCA Notices Against AI Code Ports

Microsoft and Epic Games are issuing DMCA takedowns against AI-generated code ports while using AI models themselves.

Recent AI advancements have accelerated code decompilation, resulting in a flood of AI-powered browser ports and recompilations for video games. Epic Games and Microsoft have responded by issuing numerous DMCA takedown notices against web browser ports of games like Fortnite, Minecraft, Call of Duty, and Halo. Meanwhile, both companies utilize AI tools and models. Epic Games' artists use Google Gemini and OpenAI, and a Bloomberg report stated Epic plans to use Anthropic's Claude for an upcoming game. Microsoft has committed $80 billion per year to building AI data centers, and Activision used AI for Call of Duty artwork.
