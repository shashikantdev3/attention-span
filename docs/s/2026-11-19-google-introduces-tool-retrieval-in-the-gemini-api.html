Google Introduces Tool Retrieval in the Gemini API

Google launched Tool Retrieval in preview for the Gemini API to let agents load tool parameter schemas on demand.

Google launched Tool Retrieval in preview within the Gemini Interactions API. The feature allows AI agents to manage large tool libraries more efficiently by loading parameter schemas on demand instead of sending every full schema in every prompt. Developers can enable the feature by adding a tool_search tool and setting defer_loading to true on specific tools. The model sees the names and descriptions of deferred tools while keeping parameter schemas out of context until needed. This approach reduces input token counts, lowers latency, and improves tool selection accuracy for complex tasks.
