Microsoft Introduces Agent Controls for Enterprise AI Governance

Microsoft launched agent controls, a managed Azure service that helps enterprises centrally define, manage, and evaluate policies governing AI agent behavior.

Microsoft is introducing agent controls, a managed Azure service designed to help enterprises centrally define, manage, and evaluate policies governing AI agent behavior across different frameworks, platforms, and clouds. Built on the open-source Agent Control Specification and Agent Hooks, the service brings runtime governance to enterprise AI agents. It allows organizations to enforce rules at runtime without building their own policy evaluation infrastructure. The open-source primitives set a shared standard for runtime agent governance, allowing policies to follow agents across different environments.
