Microsoft Fabric Data Agents Gain Advanced NL2SQL and DAX

Advanced natural language to SQL and DAX generation are now generally available for Microsoft Fabric data agents.

Microsoft Fabric data agents now feature advanced natural language to SQL and DAX generation. Data agents let users ask questions about data in plain language. Creators connect agents to supported sources, such as SQL databases, lakehouses, Power BI semantic models, and eventhouses, and share them across Fabric, Teams, Microsoft 365 Copilot, Copilot Studio, and Microsoft Foundry. Enterprise schemas can be complex, so advanced NL2SQL and DAX generation help the agent explore schemas, validate assumptions, and refine its approach before generating a query. These capabilities are available today, and core improvements roll out to the standard runtime from November 2 to November 10.
