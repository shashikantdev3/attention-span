New Blender AI Assistant Adds Multi-Agent Workflows and MCP Server

An open-source Blender addon integrates a visual chat workspace, Model Context Protocol server, and multi-agent workflows for 3D automation.

The anujasid/blender-ai-mcp-addon repository provides an AI assistant and Model Context Protocol server for Blender. It supports visual chat, scene tools, and multi-agent workflows. Users can choose from models including OpenAI, Anthropic Claude, Google Gemini, Ollama, and OpenCode. The tool enables artists and developers to turn creative briefs into scene operations, inspect object structures, and automate repetitive tasks. It features team chains with managers, workers, and reviewers. The release bundle targets Windows x64 with Blender 4.2 or later under the MIT license, with 532 stars on GitHub.
