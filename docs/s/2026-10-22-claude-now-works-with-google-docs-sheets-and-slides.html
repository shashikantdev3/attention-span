Claude Now Works with Google Docs, Sheets, and Slides

Claude for Google Workspace is now in public beta on all paid plans, adding Claude directly to Docs, Sheets, and Slides.

Claude for Google Workspace is now in public beta on all paid plans. It allows users to work with Claude directly in open Google Docs, Sheets, and Slides via a sidebar. Claude can read files, see selected content, and make edits. In Sheets, it can write formulas, build pivot tables, and pull ranges into Python. In Slides, it can build new slides using deck layouts and themes. Additionally, new Google Docs, Sheets, and Slides connectors allow users to create and edit files directly from Claude in the chat.

Claude is now like a helpful friend who sits next to you while you write, draw, or make lists in your computer notebooks, and can even write in them for you if you ask.

Why it matters

Integrating directly into office productivity suites removes context switching by letting AI assistants read, write, and execute code within native document environments.
