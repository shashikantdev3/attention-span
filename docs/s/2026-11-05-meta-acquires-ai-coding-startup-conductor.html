Meta buys Conductor, which runs many AI coding agents in parallel

Meta has acquired Conductor, an AI coding startup that lets software engineers deploy multiple agents into parallel workspaces.

Meta has acquired Conductor, an AI coding startup founded in 2024 that launched its core product last summer. Conductor allows users to spin up software projects by deploying multiple agents into parallel workspaces. The startup uses agents from major labs like Anthropic and OpenAI. Founder and CEO Charlie Holtz announced that the team is joining Meta. Conductor core features will continue to work until early next year, except for the cloud service which shuts down on November 20. Meta confirmed the acquisition but provided no further details.
