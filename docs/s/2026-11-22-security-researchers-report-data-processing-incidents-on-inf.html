Security Researchers Report Data Processing Incidents on Inference Providers

OpenRouter responded to security researcher findings regarding data processing incidents and policy violations on certain inference providers.

Security researchers reported that certain inference providers had data compromised or showed evidence that data policies were not being upheld. OpenRouter collaborated with researchers and providers to understand the findings. These findings did not show any breach or unauthorized access of OpenRouter. OpenRouter off-boarded three providers based on investigations, removed 125 endpoints from Zero Data Retention eligibility, and notified all potentially affected customers. Work is underway to adapt the testing approach for ongoing checks, conduct technical verification of network paths, and require appropriate assurances before restoring Zero Data Retention eligibility.
