Meta Releases Muse Wonder and Muse Wonder Full Frontier Models

Meta released its first frontier artificial intelligence models, Muse Wonder and Muse Wonder Full, featuring active memory and agent capabilities.

Meta's Superintelligence Lab released a pair of new state-of-the-art models on Monday named Muse Wonder and Muse Wonder Full. These models represent the company's first attempt at a frontier model. Wonder and Wonder Full achieve comparable benchmark scores to Fable 5.1 and GPT-6 Astra. Accessed through the Meta Model API, Wonder costs $4.00 per million input tokens and $20.00 per million output tokens. Wonder Full is only available to Muse Code subscribers. Both models power the Muse agent and include active memory to retain and synthesize user information over time.
