Opinion argues all AI-generated code should be open source

An opinion piece argues that AI-generated code must be open source because models use scraped data and lack human copyright.

An online article argues that all code generated by artificial intelligence should be open source. The reasoning is that AI models were trained on a massive corpus of open source code and Stack Overflow data without proper permission or attribution, which turns collective knowledge into closed-source code. Additionally, purely AI-generated code is not written by a human and should not be copyrightable, similar to the monkey selfie dispute and Wikimedia Commons policies. The author suggests developers release AI-generated code under open source licenses or dedicate it to the public domain.

Like I am 5

AI models learn by reading lots of code written by humans. Since machines cannot hold copyrights, people argue the code they make should be shared with everyone.

Why it matters

Releasing AI-generated code under open source licenses addresses copyright and attribution concerns.
