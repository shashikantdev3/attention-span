Hugging Face Routes Model Requests Through OpenRouter

Hugging Face now routes language model requests through OpenRouter for price, speed, and reliability.

Hugging Face now routes language model requests through OpenRouter to automatically select providers based on price, speed, and reliability. Separate API keys for language models are no longer needed, and Hugging Face bills directly without markup. Suffixes and session headers allow developers to control provider selection. OpenRouter measurements show capacity errors dropped 46 percent, time to first token improved by 16.9 percent, and throughput rose by 16.3 percent. Meanwhile, Nvidia is buying Hugging Face for $12.9 billion, and Stripe agreed to acquire OpenRouter for more than $7 billion.
