Anthropic describes agent memory design, including dreaming and tests on CL-Bench and Pokémon Red

Anthropic explains how it thinks about agent memory, including a process called dreaming, and shares evaluations on CL-Bench 1.0 and Pokémon Red.

Anthropic published a post on the components of agent memory. It defines agent memory as knowledge Claude gains from experience and keeps between sessions as context it can read later. It describes dreaming, where an agent reflects on logs to fix mistakes or write new notes. On CL-Bench 1.0, Claude Opus 5 was the first model to close the learning loop. In Pokémon Red, Claude Sonnet 3.7 wrote 413 memory files across 225 folders and earned one badge. The source text cuts off before the Claude Fable 5 results.

Like I am 5

Imagine keeping a diary while you play. Later, you read it over and tidy it up, so you keep the useful tips and drop the rest.

Why it matters

Teams building agents get a concrete picture of memory: save a few checked rules instead of every event, and review logs offline to fix mistakes and write better notes.
