Apple adds $49.99 Intelligence Usage Packs, starting with Logic Pro

Apple's Logic Pro now offers a one-time $49.99 Intelligence Usage Pack so users can keep using Apple Intelligence features that have usage limits.

Apple updated Logic Pro with a "Buy More Usage" option for a one-time price of $49.99. The packs let users keep using certain Apple Intelligence features that have usage limits because they rely on cloud-based AI models from OpenAI or Google Gemini. Only the purchasing Apple Account can use a pack, and Family Sharing isn't supported. Unused usage rolls over month to month but expires 12 months after purchase. In Logic Pro, the limit is affected by the complexity of conversations with the assistant. Apple is expected to add the option to other Creator Studio apps this month.
