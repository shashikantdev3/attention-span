Big Arrow on the Screen Draws UI Hints for AI Agents

A new macOS command-line tool lets AI agents paint big arrows, boxes, and text on your screen to point out specific interface elements.

The big-arrow-on-the-screen project is a macOS command-line tool and skill for Claude Code and Codex. It allows AI agents to draw large arrows, boxes, and text on top of windows to show users exact buttons or elements to click. The tool requires no macOS permissions, features no daemons or telemetry, and is built as a single Swift binary under the MIT license. It received 361 stars in its first two days from individuals at companies such as Apple, NVIDIA, and AMD.

Like I am 5

Just like pointing your finger at a TV screen to show a friend where to click, this tool lets an AI draw a big arrow on your computer screen so you know exactly what button to press.

Why it matters

AI agents can visually guide users to precise interface controls instead of printing text instructions into a terminal.
