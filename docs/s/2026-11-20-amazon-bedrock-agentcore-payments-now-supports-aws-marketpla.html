Amazon Bedrock AgentCore payments now supports AWS Marketplace

Amazon Bedrock AgentCore payments now allows AI agents to buy x402-enabled software, APIs, and data directly on the developer's AWS bill.

Amazon Bedrock AgentCore payments extends its autonomy to AWS Marketplace. AI agents can now discover and purchase x402-enabled software, APIs, data, and content. Payments are settled in USD on the agent developer's AWS bill, removing the need for stablecoin wallets or API keys. Developers can set spending limits and approved sellers using AgentCore policy. Transactions are auditable in AWS CloudTrail and AWS Cost Explorer. At launch, AWS Billing supports the x402 exact scheme, where the seller quotes a fixed price for each request. The feature also includes a new AWS Marketplace connector in AgentCore Gateway.
