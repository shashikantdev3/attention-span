Claude now builds interactive websites inside canvas graphics

Claude can now embed real, interactive HTML elements inside canvas graphics and 3D effects.

Claude can now embed text, buttons, and other web elements into complex graphics and 3D effects. This feature is called HTML-in-Canvas. It places real page elements inside canvas graphics while keeping them fully interactive and accessible. Felix Rieseberg from Anthropic wrote on X that Claude can now build sites with the feature. A demo page shows 15 examples, including websites rendered as knitting patterns or 3D cubes. Google is developing HTML-in-Canvas as a web standard. The feature works in Chrome and Edge starting with version 157 and in Claude desktop apps from version 5.11492.

Like I am 5

Normally, drawings on a web page are just flat pictures you cannot click inside. This feature lets you put real, clickable buttons and words directly on top of those drawings.

Why it matters

Claude can now build complex graphics that still contain real text and clickable links.
