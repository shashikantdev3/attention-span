Perplexity releases Decider v1.3 and Decider Flash v1.3 decision models

Perplexity released Decider v1.3 and a smaller Flash version, general-purpose classifiers that return probabilities and add a new locate feature for extracting text.

Perplexity released Decider v1.3 and Decider Flash v1.3, a smaller model distilled from Decider v1.3. Both are on Hugging Face under Apache license, through OpenRouter, and the Perplexity Decisions API. A decision model takes an input and several questions, then returns a probability distribution over answers in a single forward pass. It handles Yes/No, multiple choice and score questions. Version 1.3 uses bidirectional attention, better-curated training data and a refined training recipe. It also adds locate, which returns exact matching text from the input with start and end character positions, for tasks like named entity recognition and extractive question answering.

Like I am 5

Imagine a helper who reads a story once and then answers many quick questions about it by pointing to A, B or C, instead of writing out long answers. It can also underline the exact words you ask for.

Why it matters

Routing, moderation, reranking and judging tasks can run on a model that scores several questions about one input in a single pass, rather than a generative LLM writing out answers token by token.
