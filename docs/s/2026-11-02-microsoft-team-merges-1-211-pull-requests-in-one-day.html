Microsoft's Copilot Cowork team merged 1,211 pull requests in one day, mostly written by agents

A Microsoft team building Copilot Cowork had nine engineers merge 1,211 pull requests into the backend main branch in a single day.

In January, a small team at Microsoft started building Copilot Cowork, an agentic execution layer that performs multi-step workflows. On October 21, nine engineers merged 1,211 pull requests into the backend main branch. Agents wrote most of the code during the four-and-a-half-month journey from an empty repository to worldwide general availability. Automated checks and agent reviewers examined every change. Human review focused on higher-risk changes, production impact, and cases where checks or reviewers disagreed. The team also migrated their live runtime from Python to Rust while the system was active.
