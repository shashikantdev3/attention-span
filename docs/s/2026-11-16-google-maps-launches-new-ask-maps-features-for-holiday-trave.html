Google Maps Launches New Ask Maps Features for Holiday Travel

Google Maps is launching new Ask Maps features to help users plan itineraries, find appointments, and search saved lists.

Google is launching new Ask Maps features to help with holiday travel and daily errands. Users can build custom road trip itineraries, get route tips, find local appointments, and search saved lists. The new agentic capabilities allow Ask Maps to find beauty, pet care, auto, and home repair appointments online and call local businesses. Updates are rolling out on Android and iOS across more than 200 global regions. Travel itineraries and list search are available everywhere Ask Maps is offered. Route tips and finding appointments are launching first in the United States.
