Brave Search API now accepts agentic payments via x402 protocol

Brave Search API now lets AI agents pay per request in USDC on Base using the x402 protocol, with no API key or account needed.

Brave added support for x402 agentic payments to its Brave Search API. Endpoints behind x402 require payment on every request instead of authentication. A request without payment gets an HTTP 402 Payment Required response with the price and payment details. The agent signs a USDC payment and retries. Once verified, the search runs and results come back with a receipt from the Base blockchain. Brave runs its own facilitator that accepts USDC on Base. Other networks and stablecoins are coming soon. LLM Context, web, news, image, video and local endpoints each cost $0.005 ($5 per 1,000). Gas fees are covered for a limited time. Brave points to Purl Wallet, a Stripe-developed CLI wallet, as the easiest path.

Like I am 5

Imagine a vending machine. You don't need a membership card. You just put in coins each time and get your snack. Now a robot helper can do the same to ask for search answers.

Why it matters

Agents can buy search results on demand with a funded wallet, so there is no account signup, plan choice or API key to manage.
