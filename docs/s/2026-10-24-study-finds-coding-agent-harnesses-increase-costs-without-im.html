Study Finds Coding Agent Harnesses Increase Costs Without Improving Results

A new study reveals that switching between coding agent harnesses barely changes performance compared to rerunning the same setup, while costs can triple.

Two researchers at Shandong University tested five models across three coding agent harnesses, including Claude Code, OpenCode, and mini-SWE-agent. They found that swapping harnesses barely moves results more than running the exact same setup twice. Performance across harnesses was statistically equivalent, except for OpenCode trailing behind the others. About half of OpenCode's deficit stems from an output limit. Costs per task can triple depending on the harness, primarily driven by the size of the system prompt and tool descriptions that get resent with every step.

Testing different software wrappers around an AI worker showed that the worker performs about the same either way, but the wrapper can make the job cost three times more.

Why it matters

Understanding that harness differences often amount to random noise helps teams evaluate whether expensive framing systems are actually worth the extra token costs.
