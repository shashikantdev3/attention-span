OneLake external-location support for Azure Databricks Unity Catalog reaches GA in Fabric

Supported Unity Catalog-managed data can now be stored directly in OneLake, generally available in Fabric and in preview on the Azure Databricks side.

Microsoft says OneLake external-location support for Azure Databricks Unity Catalog is now generally available in Microsoft Fabric. OneLake Security is enabled by default for Azure Databricks Storage items. On the Azure Databricks side, the feature is in preview. Supported Unity Catalog-managed data can be stored directly in OneLake. Azure Databricks keeps providing compute and Unity Catalog management. OneLake provides the storage destination and Fabric-side data-access controls. Microsoft says this can reduce data copies, synchronization pipelines and separate access management across storage locations. The release builds on an earlier Beta announcement.

Why it matters

Teams running both Azure Databricks and Fabric can keep one copy of data in OneLake, which cuts sync pipelines and splits of access control across storage locations.
