Azure Content Understanding Adds GPT-5.6, GPT-6, and GPT-6.1 Models

Azure Content Understanding now supports new model families, giving developers more choices for document, text, speech, and video workflows.

Azure Content Understanding now supports the GPT-5.6, GPT-6, and GPT-6.1 model families. This update expands options for document, text, speech, and video workflows alongside the existing GPT-5 series. Microsoft updated its model recommendations and shared evaluation data. For standard document extraction, users can start with GPT-6.1 Sol, add GPT-6 Luna for low token costs, or test GPT-6 Astra when quality improvements justify a premium. The service allows testing with a schema only or with labeled examples to balance quality and cost before changing model budgets.
