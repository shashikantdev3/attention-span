Google Open-Sources TorchTPU as a Native PyTorch Backend for TPUs

TorchTPU brings native PyTorch support to Google TPUs, allowing models in Transformers and Diffusers to run directly on TPU hardware.

Google open-sourced TorchTPU, a native PyTorch backend for Tensor Processing Units. Running PyTorch on TPUs previously required using torch_xla or JAX. With TorchTPU, developers can write regular PyTorch code and treat TPUs as a standard device. The Hugging Face ecosystem now natively supports TPUs across Transformers and Diffusers without requiring Optimum TPU. Models can be loaded onto TPUs by passing device_map="tpu" or pipe.to("tpu"). Users can also apply torch.compile, use Pallas kernels, or shard large models across multiple chips using TensorParallelConfig.
