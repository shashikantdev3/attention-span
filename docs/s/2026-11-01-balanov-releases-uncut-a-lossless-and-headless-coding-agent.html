Balanov Releases Uncut, a Lossless and Headless Coding Agent Harness

Uncut is a tiny, lossless, headless coding agent harness packaged as a 7 MB static Go binary with four tools.

Balanov released Uncut, a tiny coding agent harness for shell pipelines, CI jobs, containers, and agent experiments. The tool consists of a 7 MB static Go binary with four tools and plain stdin and stdout. It features no TUI, telemetry, plugin system, background agents, automatic retries, or context compaction. Uncut sends the entire conversation on every model call without truncating file contents or combined command output. It exits with an error if a provider cuts a response at its output limit. It supports Linux, macOS, and Windows for amd64 and arm64 architectures under the MIT license.

Like I am 5

Uncut is a tiny digital helper that reads your code instructions, runs commands, and sends the exact text straight to an AI model without summarizing or hiding anything.

Why it matters

Eliminating silent context cuts and summarization ensures that coding agents process exact inputs and raw tool results without hidden modifications.
