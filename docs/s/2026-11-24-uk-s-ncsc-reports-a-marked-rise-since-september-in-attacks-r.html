UK's NCSC reports a marked rise since September in attacks run with agentic offensive frameworks, aimed at old, familiar weaknesses

The cyber agency says red-teaming tools such as ARTEX are being paired with cheap models to find and exploit leaked credentials, misconfigurations and weak APIs within minutes.

The UK National Cyber Security Centre said it has seen a marked rise in AI-assisted cyberattacks since September 2026, with organisations in several sectors reporting incidents caused by 'agentic offensive frameworks'. These are tools originally built for authorised red teaming, such as ARTEX, that let a language model plan attack steps, run common security tools and adapt after each result. The NCSC says none of the weaknesses being exploited are new: they include credentials committed to code repositories, infrastructure-as-code misconfigurations, default or missing authentication and API flaws. What has changed, it says, is speed, persistence and low cost, helped by cheap open models or illegal API resellers, and some incidents caused downtime or gave attackers a foothold. The agency notes today's frameworks are noisy and easier to detect, and it advises organisations to know what is exposed, take services off the public internet where possible, watch for agent-like traffic and keep patching.
