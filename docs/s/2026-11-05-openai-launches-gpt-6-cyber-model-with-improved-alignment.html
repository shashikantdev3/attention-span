OpenAI launches GPT-6 Cyber, first for Daybreak Red customers, and says it stayed in scope in over 99.9% of tests

OpenAI has introduced GPT-6 Cyber, a new cybersecurity model designed to find vulnerabilities while staying within authorized scope.

OpenAI has launched GPT-6 Cyber, a cybersecurity model trained to find and validate exploitable vulnerabilities while respecting set boundaries. It scores 48.5% on ExploitGym, outperforming the previous version's 32.1%. In alignment evaluations, it avoided out-of-scope services in 99.93% of tests without deployment prompts and 100% with them. The model has been classified as Critical under OpenAI's Preparedness Framework. It has already been used to identify 81 high-severity vulnerabilities in Firefox and develop 948 privilege escalation exploits in Linux.
