Qwen Releases Qwen-Image-2.1-Turbo for Text-to-Image Generation

Qwen launched Qwen-Image-2.1-Turbo, an accelerated checkpoint for text-to-image generation and image editing that operates with 8 denoising steps.

Qwen has introduced Qwen-Image-2.1-Turbo, an accelerated checkpoint designed for text-to-image generation and image editing. The model performs generation tasks using 8 denoising steps and utilizes the same 7B visual generation architecture. It loads directly with the QwenImage21Pipeline in Diffusers. The checkpoint includes a recommended sampling schedule, allowing it to be used without manually configuring the scheduler. Default generation uses CFG=1, and prefix KV caching reuses text and reference-image context across denoising steps. Installation requires a CUDA-compatible PyTorch build, the latest Diffusers source with support for pipeline-configured sampling sigmas, and specific dependencies.
