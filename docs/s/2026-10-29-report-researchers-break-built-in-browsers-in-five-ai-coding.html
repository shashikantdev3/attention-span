Researchers break the built-in browsers of five AI coding assistants

Researchers found security vulnerabilities in the embedded browsers of five AI coding assistants, leaving some tools unpatched.

Forever Security discovered vulnerabilities in the built-in browsers of five AI coding assistants, namely Cursor, GitHub Copilot, OpenAI’s Codex, Microsoft’s VS Code, and Anthropic’s Claude Desktop. Vendors loosened embedded browsers so AI tools could preview local projects. The researchers found this broke standard browser security rules. In Claude Desktop and VS Code, background web workers allowed a local project file to read the rest of the disk. Codex lacked folder checks entirely and remained unpatched as of October 29. Cursor and GitHub Copilot issued security fixes. Anthropic and Microsoft declined reports due to Workspace Trust prompts.
