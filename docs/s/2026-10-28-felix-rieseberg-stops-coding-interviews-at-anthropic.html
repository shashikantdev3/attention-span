An Anthropic hiring manager drops coding interviews because Claude now does them better

An Anthropic hiring manager explains why coding interviews are dead and how junior engineers can succeed using AI.

Felix Rieseberg, a hiring manager at Anthropic, stopped using traditional coding interviews because Claude is now better at small coding challenges than humans. Rieseberg argues that AI gives junior engineers and newcomers a massive advantage because execution is no longer expensive. Instead of relying on years of framework experience, junior engineers can pick business impacts, create radical ideas, and build working prototypes over a weekend. Fresh perspectives help newcomers spot friction and opportunities that old-timers miss.
