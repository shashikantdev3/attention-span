Microsoft says China's Salt Typhoon and Crystal Typhoon and North Korean groups now use the ARTEX agent framework in intrusions

Microsoft's new report names six threat groups using the open-source tool and says one campaign produced more than 151,000 failed sign-ins.

Microsoft Threat Intelligence published a long report on ARTEX, the agentic hacking framework the FBI warned about earlier this month, and says six threat actors have now built it into their tooling. The new names include the Chinese state-backed groups Salt Typhoon and Crystal Typhoon, which Microsoft says use it for network reconnaissance, credential attacks and web application exploitation, plus the North Korean groups Onyx Sleet and Pearl Sleet. Microsoft describes ARTEX as a system that coordinates LLM agents to move from reconnaissance to privileged access in minutes, while stressing that it adds no new attack techniques and relies on common penetration testing tools. The code was posted on GitHub in July and removed by its developer in October, but forks remain, and Microsoft says a China-based security firm now claims ownership and sells a commercial version. In one Storm-0940 campaign, Microsoft counted more than 151,000 failed sign-ins, peaking at 2,900 a minute. It advises defenders to watch for behavior rather than specific tools.
