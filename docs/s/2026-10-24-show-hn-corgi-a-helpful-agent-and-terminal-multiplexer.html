Show HN: Corgi, a Helpful Agent and Terminal Multiplexer

A developer has built Corgi, a terminal multiplexer designed to track multiple AI coding agents, background processes, and resource usage.

A developer built Corgi, an agent and terminal multiplexer inspired by Herdr. Corgi keeps watch over background agents, tracks token usage, and displays what each agent is doing. It includes a unified launcher for Codex, Claude Code, and Pi, supporting fast search and session resumption. The tool features terminal improvements such as clickable links, image pasting via command plus v on SSH with Ghostty Nightly, and live CPU, memory, and GPU usage tracking per workspace. The creator designed it to improve terminal ergonomics while managing multiple AI agents.
