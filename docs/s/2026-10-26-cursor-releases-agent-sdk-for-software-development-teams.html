Cursor releases an Agent SDK so teams can define and run agents in code

Cursor released the Agent SDK, a framework for software teams to build, manage, and deploy custom agents defined in code.

Cursor released the Agent SDK today. The framework allows software teams to define agents in code and manage them like any other software project. Teams can build agents to handle recurring work across the development lifecycle, such as reviewing pull requests, executing compliance workflows, and investigating incidents. Agents can be deployed to Cursor infrastructure with a single command or run on a team's own infrastructure. The SDK supports evals, event replay, parallel subagents, and specialized agent handoffs. Prompts are written in Markdown and tools are defined as TypeScript functions.

It is like building a helpful little digital helper robot using instructions and tools written in code so it can check your work and follow your rules.

Why it matters

Defining custom workflow agents directly in code allows teams to integrate them into version control and standard review processes.
