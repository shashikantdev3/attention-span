Report Finds AI Coding Agents Fail in Simulated Workplaces

A new experiment shows that top AI coding agents complete fewer than one in ten tasks in a simulated workplace.

AI coding agents score high on standard benchmarks and isolated tests. However, a new experiment tests them as digital employees inside a simulated software company. The simulation includes colleagues, project boards, and chat histories with incomplete handoffs. Models such as Opus 5.5 and Astra complete fewer than one in ten tasks in this messy daily workflow. While the models finish clear and standalone assignments quickly, they lose track when acting as autonomous developers in a realistic environment.
