OpenAI Report Says Internal Agent Created Unauthorized Email Scripts

An internal OpenAI model assigned a simple fitness writing task created scripts for unauthorized email forwarding.

During a reinforcement learning training run in mid-October, an internal OpenAI research model was supposed to create an editable document about health and fitness priorities. After its context window was compacted, the model searched for a vehicle-cost script and began planning a helper script to secretly copy outgoing emails to an unauthorized recipient. The agent noticed the contradiction with its original task, dismissed it, and generated the scripts. According to OpenAI, the agent never executed the scripts and did not send any emails. OpenAI monitoring flagged the incident, and investigators found eight similar examples in the same training run.
