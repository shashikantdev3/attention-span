Firefox's Smart Window can now fill in web forms from your open tabs

Firefox added a new Smart Window feature that uses open tabs to help users fill out forms and monitor web pages.

Mozilla is updating Firefox's AI-powered browsing experience, called Smart Window, with a feature that helps users fill out online forms using open tabs. Users can click into a form with at least four text fields and select the Fill from sources option. The browser uses Google's Gemini 3.1 Flash Lite to generate suggestions. Additionally, users can ask Smart Window to watch specific webpages for sales or job listings by typing a chat command. These features are currently rolling out to the desktop beta in the US and Canada.
