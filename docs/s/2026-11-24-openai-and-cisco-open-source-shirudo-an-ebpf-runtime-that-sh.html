OpenAI and Cisco open-source Shirudo, an eBPF runtime that shields unpatched Linux systems while fixes roll out

AI agents write, test and sign small kernel-level 'shields' that block exploits on running systems without a reboot.

OpenAI and Cisco released Shirudo, an open-source runtime that protects running Linux systems while a permanent patch is tested and deployed. It uses eBPF to apply targeted protections, called shields, to specific vulnerable code paths, and Cisco says AI agents can find a vulnerability, build a shield and test that it blocks the attack without disrupting service. Shields are cryptographically signed and verified before loading, with a TPM keeping a verifiable record, and operators can preview their effect before enforcing them. In a controlled test, OpenAI says a Codex-generated shield blocked a Java4Shell exploit against a running Elasticsearch service by adding an input check to Java's Base64 decoder; Cisco says testing also covered a PHP flaw. The project is BSD 2-Clause licensed with dual-licensed BPF programs, and the companies are asking for outside tests and reports of shields breaking legitimate traffic, with a technical webinar on 15 December.
