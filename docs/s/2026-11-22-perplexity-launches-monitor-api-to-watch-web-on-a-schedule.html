Perplexity Launches Monitor API to Watch Web on a Schedule

Perplexity launched a new Monitor API that searches the web on a schedule and sends relevant changes to AI agents.

Perplexity launched a new Monitor API that runs searches on a schedule and sends relevant changes directly to AI agents via webhook. The service includes web monitors for regular search topics and page monitors for tracking specific pages. A built-in decision model filters out unimportant results based on relevance, source credibility, novelty, and timeliness. The API costs $1 per 1,000 requests and aims to free engineering teams from maintaining custom code for recurring searches.
