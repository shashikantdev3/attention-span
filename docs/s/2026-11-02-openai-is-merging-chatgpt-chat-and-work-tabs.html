OpenAI is merging ChatGPT's Chat and Work tabs

OpenAI is merging the ChatGPT chat and work tabs to provide a single place for exploring ideas and building projects.

OpenAI is merging the Chat and Work tabs within the ChatGPT desktop app experience, according to an email sent to users. The update will initially be available to select users for feedback before a wider rollout. Users will be able to bring in files and plugins to build websites or presentations in one place. Codex will remain a separate experience in the desktop app. Both ChatGPT and Codex will draw tokens from the same allowance pool after the transition.
