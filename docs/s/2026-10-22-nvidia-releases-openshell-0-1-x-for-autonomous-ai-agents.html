Nvidia Releases OpenShell 0.1.x for Autonomous AI Agents

Nvidia has released OpenShell 0.1.x, a runtime designed to govern what autonomous AI agents can touch via policies and isolation primitives.

Nvidia released OpenShell version 0.1.x, providing a runtime for fleets of autonomous AI agents. OpenShell governs agent actions by instrumenting the kernel to enforce policies on file access, system calls, and network connections at runtime. It also uses formal verification to check policy changes before they are applied. The software runs in isolated sandboxes and adds credentials only to requests bound for approved endpoints. Version 0.1.x introduces a stable release cadence, new isolation primitives, an expanded extension surface, and new APIs. It requires Linux, macOS on Apple Silicon, or Windows with WSL 2, along with Docker, Podman, or host virtualization.
