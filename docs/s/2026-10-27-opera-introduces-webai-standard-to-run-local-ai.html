Opera proposes WebAI, a web standard for running AI models locally in the browser

Opera has introduced a new web standard called WebAI that allows users to run AI models directly in its browser without cloud reliance.

Browser maker Opera has introduced a new web standard called WebAI. The standard lets users run AI models directly inside the browser without relying on the cloud. It supports various open-weight models, including Google's Gemma and Apple's on-device foundation model on Macs. Opera is making the features available as an early preview in its flagship Opera One browser. Opera GX and Opera Neon will soon get the same features. Users must opt into the feature. Running models locally keeps personal information on the user's device and gives them more control, though it puts more demand on computer hardware.
