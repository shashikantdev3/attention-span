OpenAI is buying Pierre Computer Company to bring its code storage into Codex

OpenAI announced it will acquire Pierre Computer Company to expand Codex tools for building, understanding, and reviewing code.

OpenAI announced plans to acquire Pierre Computer Company, the startup behind Code Storage and open-source developer tools like Trees and Diffs. These libraries already power file browsing and change reviews in the Codex app. The acquisition aims to adapt Git workflows for teams working with coding agents. Pierre's open-source projects will remain open-source. Customers can continue using Code Storage after the acquisition closes while OpenAI works to bring its features into Codex. The deal is subject to customary closing conditions and regulatory approvals.
