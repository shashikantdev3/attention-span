Developer ports TypeScript compiler to Rust using LLMs

A developer successfully ported the TypeScript compiler, checker, and language server to Rust using various language models.

A developer used language models to port Microsoft's TypeScript compiler, checker, and language server to Rust. OpenAI models spent over $420,000 in API tokens over multiple months while reaching 84 percent compatibility. Later, Claude Opus 5.5 built a working version from scratch in ten hours with a token spend of $24,047. The resulting tool, tsc-rs, passes all 181,711 ported Go tests. On 60 open-source projects, type checking takes about half of Go's time. The tool is available via npm and supports Linux x64 and macOS arm64 platforms.
