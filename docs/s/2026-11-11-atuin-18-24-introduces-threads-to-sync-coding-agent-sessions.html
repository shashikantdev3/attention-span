Atuin 18.24 Introduces Threads to Sync Coding Agent Sessions

Atuin 18.24 introduces Threads, allowing users to search, resume, and fork coding agent sessions across multiple machines.

Atuin has released version 18.24 with a new feature called Threads. Threads enables developers to search agent sessions across machines, resume them anywhere, or fork sessions into different agent harnesses. Supported agents include Claude Code, Codex, Pi, Omp, and OpenCode. The sync engine uses end-to-end encryption, and users can use a hosted sync server, run their own, or keep sessions local. Additionally, Model Context Protocol integration allows agents to search and reference previous sessions automatically.
