GitHub details a new secret detection model and pipeline

GitHub trained a secret classifier to distinguish real credentials from lookalikes while meeting scale requirements.

GitHub released details about its model for secret detection. The new pipeline achieves 11.5 percent higher owner weighted alert precision and 86 percent lower median scan execution time for post push scanning. It also reduces serving cost by 98 percent using a compact model instead of remote LLM calls. Generic secrets make scanning difficult because the same string can be a real credential or a documentation placeholder. To solve this, GitHub trained a secret classifier specifically for its product needs to understand surrounding code and text.
