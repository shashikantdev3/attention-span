ChatGPT Desktop App Now Available on Amazon Bedrock in AWS GovCloud

Organizations can use the ChatGPT desktop app with Amazon Bedrock in AWS GovCloud using IAM and Regional network controls.

The ChatGPT desktop app is now available on Amazon Bedrock in AWS GovCloud, providing access to OpenAI frontier models through Work and Codex components. Work handles complex, multi-step tasks, while Codex acts as a coding agent for software development. This configuration routes model requests through Amazon Bedrock Mantle in us-gov-west-1, allowing access to be governed using AWS Identity and Access Management and existing network controls. Processing stays within the selected AWS Region for data residency requirements, and zero data retention is supported where prompts and responses are not written to durable storage.
