Parsimony Measures How Much Excess Code AI Models Add

Parsimony is an open-source benchmark measuring how much extra code AI models add to codebases.

Existing benchmarks measure solve rate, token output, and cost. They do not punish excess code, which makes codebases harder to work with long term. Parsimony takes published patches from DeepSWE, SWE-bench Verified, and SWE-bench Live. It counts coding units, such as syntax elements, statements, calls, names, and literals, instead of lines of code. Deleted code is subtracted to measure net units. GPT-6 and Claude 5.5 ran on 3 to 10 tasks on personal subscriptions and appear as faded circles without a rank.

Like I am 5

Most tests only check if the robot finishes the chore, but this test also checks if the robot leaves a messy pile of extra toys behind.

Why it matters

Evaluating AI models on net code units instead of raw output penalizes bloat and helps maintain clean codebases.
