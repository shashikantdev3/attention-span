Agweb is a macOS browser built for coding agents

Agweb is a macOS browser built on WebKit that lets coding agents drive the web from the shell without stealing window focus.

Agweb is a browser for coding agents on macOS built on WebKit. It features a single window that never steals focus, while agents drive it from the shell using commands similar to Playwright. Idle tabs are throttled and suspended to save resources. A dashboard shows every tab of every agent live. Named profiles allow multiple agents to share logins simultaneously. Native macOS pointer events support hover menus and drag-and-drop. Built-in blocking uses uBlock Origin lists. The application requires macOS 26 or later and provides command-line tools and agent skills.

Like I am 5

Agweb is like a silent helper watching the internet for your little robot friends, letting them click around without ever popping up to steal your mouse.

Why it matters

Running multiple coding agents simultaneously becomes possible without browser windows stealing focus or consuming excessive system resources.
