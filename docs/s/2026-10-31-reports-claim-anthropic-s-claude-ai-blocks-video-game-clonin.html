Users report Claude refusing to recreate existing video games and other reverse-engineering tasks

Users report that Anthropic's Claude AI models block reverse-engineering and video game recreation tasks.

Multiple user claims suggest that Anthropic's Claude Code and Opus 5.5 models are blocking reverse-engineering attempts and video game recreation. The issue may be linked to a text rule instructing the model to avoid recreating specific existing games. Users also report refusals for tasks like analyzing crash dumps, clearing TV junkware, and developing anti-cheat systems. Anthropic introduced a Cyber Verification Program on October 6, though the link between cybersecurity restrictions and game rules remains unconfirmed. OpenAI also deactivated an account for cleaning TV software. There is no official statement from Anthropic or other AI companies.
