Codex CLI 0.171.0 Release Adds New Models and TUI Workspace

Codex CLI 0.171.0 introduces GPT-6.2 Sol and Astra to model catalogs, enables the TUI workspace by default, and adds custom MCP status line options.

Codex CLI version 0.171.0 adds GPT-6.2 Sol and Astra to model catalogs, with Sol set as the default selection. It enables the TUI workspace by default with searchable document previews, image previews, and subagent transcripts. The update adds configurable undo and redo shortcuts for the non-Vim prompt composer, a new command to start or resume noninteractive sessions on an existing app server, and commands to manage local remote control. Bug fixes preserve drafts and follow-ups when switching sessions and fix enterprise MCP sign-in issues. Source builds and release tooling were updated to Rust 1.99.1.
