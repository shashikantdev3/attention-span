Anthropic releases FlashProve for cryptographic proofs that a model really ran

Anthropic released FlashProve, an open-source system using zkSNARKs to generate cryptographic proofs verifying that specific AI models produced given responses.

Anthropic released FlashProve, a system for provable inference using a cryptographic proof type known as a zkSNARK. The system lets a model provider commit to a model and prove that each response came from that model without revealing the private weights. For a 400 billion parameter mixture of experts model, a single H100 GPU generates proofs at around 110 tokens per second with a proof size of about 19 megabytes per 1,024-token request. Anthropic released code, documentation, and Lean proofs under the Apache 2.0 license to allow other teams to inspect and improve the work.
