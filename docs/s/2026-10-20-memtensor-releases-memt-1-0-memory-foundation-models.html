MemTensor Releases MemT-1.0 Memory Foundation Models

MemTensor introduces MemT-1.0, a new family of memory foundation models that integrates dynamic local memory and trainable hyper memory into model computation.

MemTensor released MemT-1.0, a new generation of memory foundation models featuring native memory blocks. The model family includes MemT-1.0-Nano and MemT-1.0-Flash. It uses dynamic local memory, trainable hyper memory, and Mixture-of-Storage for scalable capacity. Trained on 34B tokens via a two-stage pipeline, it reduces persistent storage by approximately 66x compared to full-context KV cache at 128K history length while achieving about 1.86x end-to-end inference speedup. Across 11 benchmarks, MemT-1.0-Flash and MemT-1.0-Nano rank first and second among evaluated parametric memory methods.
