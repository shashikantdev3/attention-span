Docker Agent for Building and Running AI Agents

Docker Agent lets you build, run, and share AI agents with a declarative YAML config, tools, and multi-agent orchestration.

Docker Agent is a Docker CLI plugin that lets you create and run intelligent AI agents that collaborate to solve complex problems without code. You can define agents in YAML, assign tools, and run them using commands like docker agent. Key features include multi-agent architecture, a rich tool ecosystem with built-in tools and Model Context Protocol servers, AI provider agnosticism across OpenAI, Anthropic, Gemini, AWS Bedrock, Mistral, xAI, and Docker Model Runner, and RAG capabilities with pluggable retrieval. You can package and share agents by pushing them to any OCI registry.
