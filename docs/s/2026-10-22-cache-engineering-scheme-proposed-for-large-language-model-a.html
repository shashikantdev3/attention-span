Cache Engineering Scheme Proposed for Large Language Model Agents

Researchers propose cache engineering to let LLM agents control their active KV cache without modifying trajectories or re-prefilling context.

Large Language Model agents handle complex tasks by navigating long trajectories of observations and actions. As these trajectories grow, key-value cache I/O and storage become dominant costs. They can also exceed the maximum context length. Prior context engineering methods reduce cache size by trimming or modifying history, which invalidates cached states and forces costly re-prefilling. A new scheme called cache engineering lets agents control their active KV cache directly. Agents can use drop to exclude selected cache from future attention and repos to adjust retained keys position encodings. The AKV serving engine manages stateful cache reuse, eviction, and restoration.
