Graphicle Offers Code Graph and Memory for Coding Agents

Graphicle is a Rust program that provides code graph and memory for coding agents across multiple MCP clients.

Graphicle is a Rust program that provides a code graph and memory for coding agents. It maps repositories into a code graph, remembers project documents, decisions, and past agent sessions, and supplies coding agents with cited excerpts. It runs locally without an API key, account, or telemetry. Graphicle works with Claude Code, Cursor, Codex, VS Code, and other MCP clients. It features local sync, a single SQLite file, command line tools, and a web app for reviewing agent-proposed memories.

Like I am 5

Graphicle acts like a smart filing cabinet and a map for coding helpers, organizing all the project files and past notes so they can quickly find what they need.

Why it matters

Local coding agents gain fast, private access to structured project memory without relying on external databases or cloud servers.
