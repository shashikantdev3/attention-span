OpenAI Makes Decisions API Generally Available

OpenAI released the Decisions API to help applications and agents make fast, low-cost choices using GPT-6 Luna.

OpenAI made the Decisions API generally available on October 22, 2026. Built with GPT-6 Luna, the API helps applications and agents make near real-time decisions from text, images, and structured inputs up to 10x faster than the Responses API. Features include prompt caching, inference residency in the US and EU, native JSON inputs, and up to 400 questions per request. It supports three answer types including probability, choice, and score. It also includes a native GPT-Live integration for live voice applications and real-time avatar reactions.

It is like a multiple-choice helper that looks at pictures or words and answers questions instantly, just like choosing the right emoji while someone is talking.

Why it matters

Applications and agents can execute routine classification, routing, and scoring tasks much faster and at a lower cost.
