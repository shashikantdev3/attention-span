Researchers show LLMs can read and edit neural network weights directly

Researchers demonstrate that smart language models can directly read, fix bugs in, and write the neural network weights of smaller models.

A new discovery shows that large language models can directly read and edit the weights of smaller models without writing code or running training loops. Researchers used a smart model to inspect compiled model weights, fix bugs from failed traces, and write entire network weights from scratch. This approach cuts traditional autoresearch and code-writing loops out of recursive self-improvement processes. While currently limited to simple tasks, this new capability provides a highly efficient alternative to standard model training methods.
