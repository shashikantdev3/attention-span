Cerebras Launches Disaggregated Inference Combining GPUs and Wafer Scale Engines

Cerebras launched disaggregated inference, pairing GPUs for prompt processing with Cerebras systems for output generation to deliver higher throughput.

Cerebras launched a disaggregated inference solution that pairs GPUs for prompt processing, known as prefill, with Cerebras systems for output generation, known as decode. In a production deployment using AMD Instinct GPUs and Cerebras CS-3 systems, the configuration delivered five times the throughput per megawatt of a CS-3-only setup without losing token generation speed. The company plans to deploy this approach across hundreds of megawatts in the Cerebras Inference Cloud and partner deployments by the end of 2027. Infrastructure partners can adopt the solution using a reference architecture, an end-to-end software stack, or a decode-only SDK.

Like I am 5

Imagine a team where one person quickly reads long pages of text and hands over notes, while another person writes out the final answers at lightning speed. By splitting the work between GPUs and Cerebras chips, the system gets much more efficient.

Why it matters

Splitting prompt processing from output generation increases inference capacity and token throughput per megawatt while maintaining high response speeds.
