Alibaba Launches Qwen4-Max Model with Lower Prices

Alibaba launched Qwen4-Max, a mixture-of-experts model featuring a hybrid architecture designed to process long contexts at much lower prices.

Alibaba launched Qwen4-Max, a mixture-of-experts flagship model featuring 2.4 trillion parameters while activating 71 billion per token. The model includes a hybrid architecture that combines attention layers with a condensed state to cut compute costs on long inputs. It ranks second behind Kimi K3.1 Pro on the Artificial Analysis Intelligence Index. The model offers native image processing and a one-million-token context window. A feature called Live Delivery allows users to inspect intermediate results from autonomous agents and adjust tasks early. Alibaba charges $1.50 per million input tokens and $4.50 per million output tokens.
