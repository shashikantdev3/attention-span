Microsoft Updates Copilot on Windows With Hybrid Intelligence

Microsoft is updating Copilot on Windows to use hybrid intelligence, combining local PC context and local models with cloud capabilities.

Microsoft announced updates to Copilot on Windows featuring hybrid intelligence. With user permission, Copilot can tap into PC context, take action, and use local models when appropriate. Satya Nadella explained that Windows is becoming a home for hybrid intelligence where AI agents can run securely across local PCs and the cloud using MXC containment, upgraded Copilot experiences, on-device models, and a spectrum of AI-first Windows PCs. These range from thin-and-light laptops to RTX builder rigs and DGX-class personal AI supercomputers.
