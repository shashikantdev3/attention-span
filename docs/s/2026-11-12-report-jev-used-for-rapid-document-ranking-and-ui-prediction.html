Report: Jev used for rapid document ranking and UI prediction

At the AI Engineer Code Summit, Jev powered fast document chunk ranking and a time-off UI filler.

The AI Engineer Code Summit highlighted system one models, non‑generative models that return structured choices, scores, or probabilities and are faster and cheaper than reasoning LLMs. Diogo Almeida, co‑founder and CEO of TypeSafe AI, introduced Jev, released in September, as "reliable intelligence" for automating tasks. Glean uses Jev for zero‑shot flexibility without fine‑tuning. UiPath demonstrated a Jev tournament that ranked document chunks in under a second, even with thousands of calls. Workday showed a prototype where Jev pre‑fills a time‑off card while the user types.
