Anthropic studies 207,000 Claude sessions to see how scientists use AI

Anthropic analyzed 207,000 Claude and Claude Code research sessions and found scientists mostly use AI for data analysis and writing, not idea generation.

Anthropic studied 207,000 Claude and Claude Code research sessions using privacy-preserving methods. Claude is used more in formal sciences such as computer science, mathematics and statistics, and less in health and lab-based physical sciences. Data analysis is about one-third of sessions on Claude and nearly half on Claude Code. Scientists use it less for idea generation and data gathering, though they rank those tasks as most important in a survey. Using a simple model, Anthropic says current AI could double research output in some fields. About 40% of surveyed AI-using researchers expect AI to run full research projects on its own by 2030.
