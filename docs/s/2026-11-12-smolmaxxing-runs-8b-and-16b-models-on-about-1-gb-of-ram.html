smolmaxxing runs 8B and 16B models on about 1 GB of RAM

An open-source llama.cpp patch called smolmaxxing runs 8B and 16B mixture-of-experts models on about 1 GB of RAM by streaming weights from flash.

smolmaxxing is a patch on llama.cpp that aims to run the biggest language model possible on small, old hardware such as TV boxes, old tablets, single-board computers and routers. Two devices are covered so far, and both run 8B and 16B mixture-of-experts models on about 1 GB of RAM. It keeps part of each model in memory and reads the rest from flash as needed. Other techniques include a 1-bit lookup-table kernel, dropping rarely used vocabulary output rows, and streaming for dense models bigger than RAM. All numbers were measured on the devices. Stock llama.cpp cannot load the model files.

Why it matters

Old TV boxes, tablets and other low-memory hardware can now run 8B and 16B models locally, which widens where on-device inference is possible.
