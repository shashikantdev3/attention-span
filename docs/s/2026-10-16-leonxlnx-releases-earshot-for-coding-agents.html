Leonxlnx Releases Earshot for Coding Agents

Earshot is an open source, CPU-only tool that lets AI coding agents hear, review, and make sound.

Leonxlnx released Earshot, an open source and CPU-only tool that lets AI coding agents hear, review, and make sound. AI coding agents can write code for films or games, but they cannot normally hear what they made. Earshot turns sound into evidence an agent can reason about, such as descriptions, transcripts, and scorecards. It runs locally as a CLI, a Python API, or an MCP server. It also includes Earshot Forge, which lets agents write sounds as code using physical synthesis and real reference recordings. The tool downloads two open models on first use.

Like I am 5

Just like people listen to music to check if it sounds right, this tool gives AI computers ears so they can listen to their own audio code and fix mistakes.

Why it matters

Coding agents can now evaluate and create audio by turning sound into evidence they can reason about.
