OpenAI Shares Prompting Tips for GPT-6.2 Astra and Sol

OpenAI published new prompt templates for GPT-6.2 Astra and Sol to address brief answers, unnecessary questions, and excessive code testing.

OpenAI released new prompt templates and API changes for the GPT-6.2 Astra and Sol models. The updates aim to fix behaviors such as overly brief default answers, unnecessary follow-up questions, and excessive testing during coding tasks. Astra is built for demanding tasks, while Sol handles complex work at a lower cost. The new guidelines instruct models to make assumptions instead of waiting for permission, reuse existing code without unnecessary abstractions, and write tests only when requested. Additionally, editing conversation history in the API now discards earlier reasoning steps, which affects token costs and response quality.
