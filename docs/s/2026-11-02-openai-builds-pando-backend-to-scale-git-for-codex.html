OpenAI built Pando, a new Git backend, to keep up with Codex

OpenAI built Pando, a new Git-compatible backend designed to handle the scale and concurrent work enabled by Codex.

OpenAI developed Pando as a new backend for Git repositories to support the massive increase in monorepo size and demands caused by Codex. Pando aims to provide horizontally scalable writes for concurrent pushes and maximize read throughput to saturate network bandwidth. In production, Pando cut median push latency by nearly 5x and delivers nearly a petabyte of Git data per day. The system retains compatibility with the Git protocol and client, allowing engineers and agents to adopt it without changing their existing workflows. Aaron Friel, Taylor Blau, and Ted Nyman authored the announcement.
