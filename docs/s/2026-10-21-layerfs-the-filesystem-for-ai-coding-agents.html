LayerFS: The Filesystem for AI Coding Agents

LayerFS is presented as a filesystem for AI coding agents, featuring ephemeral computing and atomic store operations.

LayerFS is a filesystem designed for AI coding agents. Compute exists only while a command runs. Agents spend about 80 percent of their time thinking and about 10 percent in Bash. Each file tool call is one atomic Store op. Each Bash tool call mounts an ephemeral workspace and then commits.
