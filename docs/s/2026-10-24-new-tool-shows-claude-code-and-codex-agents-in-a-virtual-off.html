New Tool Shows Claude Code and Codex Agents in a Virtual Office

A new developer tool displays live activities of Claude Code, Codex, and Gemini CLI agents inside an interactive virtual office.

The whatsmyagentdoing repository provides a local tool to visualize active AI coding agents as characters in a virtual office. Agents working on a machine are rendered in a 2D canvas or a 3D environment with real-time lighting. Characters display thoughts, type on monitors, or take breaks when finished. The tool reads existing session logs written to disk by Claude Code, Codex, and Gemini CLI without needing API keys or hooks. Users can filter sessions, view lists, and track agent status locally on port 4545.
