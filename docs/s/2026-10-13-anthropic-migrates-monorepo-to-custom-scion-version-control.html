Anthropic migrates monorepo to custom Scion version control system

Anthropic built a custom version control system called Scion to handle the massive volume of code generated by its AI agents.

Anthropic transitioned its monorepo from git to a custom system named Scion to support high-frequency code changes. By September 2026, the company merged over 30,000 code changes per day. The main branch history is almost 100 GB, and CI processes perform approximately 25 million code checkouts daily. Unlike git, which is decentralized and designed for offline use, Scion assumes clients are always online. The system uses client-server asymmetry, where the server handles complex operations like merges and history queries, while clients maintain a bounded local cache. This architecture allows for horizontal scalability and programmatic access to repository data.
