OpenAI's cyber model found and patched 948 Linux root exploits in one run, for $1.2M in API costs

OpenAI says an automated pipeline using its cyber model reproduced 1,724 Linux kernel vulnerabilities and built 948 local privilege escalation exploits, then drafted patches for maintainers.

OpenAI describes a prototype pipeline that searches the Linux kernel for flaws inside a controlled research environment. In one run it analyzed 2,308 candidate findings, reproduced 1,724 vulnerabilities and produced 948 exploits that would let an unprivileged local user gain root access, at an API cost of $1.2 million. OpenAI used the exploits as evidence to decide which bugs to report first, starting with critical ones as the Linux kernel community advised, and wrote candidate patches for maintainer review. In June, as part of its Patch the Planet initiative, GPT-5.5 Cyber had produced 24 such exploits.
