Developer uses coding agents to program FPGA inference chip

Ankit Gupta used coding agents and a large token budget to program an FPGA inference chip to run an LLM.

Ankit Gupta used coding agents on AWS F2 instances to program an FPGA to run a language model with ternary weights. Running for several days, a cloud agent wrote roughly 3 million lines of C++ and Verilog code and parsed 30 million lines of output files. The experiment burned $10,000 in Claude and OpenAI tokens across hundreds of experiments. The agent increased the model speed by 33 times, moving from a baseline of 6 tokens per second to 213 tokens per second through optimizations including a head loader, a runtime expert-prefetch policy, and a router-job timing fix.
