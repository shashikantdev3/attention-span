Microsoft makes GitHub's Copilot harness available in Microsoft Foundry

Microsoft is making the GitHub-built Copilot harness available to developers and enterprise customers through Microsoft Foundry.

Microsoft announced that the multi-model Copilot harness built by GitHub engineers is now available through Microsoft Foundry. The harness serves as the orchestration layer around AI models, providing instructions, context, execution environments, and controls. It supports over twenty frontier models and open standards like MCP, agent skills, and plugins. The runtime was ported to Rust to improve performance, reduce session overhead, and lower time-to-first token. Developers can now use the managed offering to build agents that reason, use tools, and complete complex tasks without building their own model routers.

An AI model is like a brain, and a harness is the body and environment that lets that brain do actual work.

Why it matters

Building and maintaining a multi-model AI orchestration layer is no longer necessary because teams can use the same production-tested harness that powers Microsoft Copilot.
