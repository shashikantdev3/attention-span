Anthropic releases Claude for Manufacturing plugin for factory software

Anthropic released Claude for Manufacturing, a plugin that connects Claude to industrial software like Autodesk Fusion, Oracle NetSuite, Microsoft 365 and Infor to automate factory workflows.

Anthropic has released Claude for Manufacturing, a plugin that gives the AI direct access to industrial software. It connects via four universal interfaces to Autodesk Fusion, Oracle NetSuite, Microsoft 365, and Infor. It has 17 specific skills, including drafting quotes from actual inventory, comparing suppliers and generating quality reports. With an added Infor plugin, Claude can order from backup suppliers and reschedule production after human approval. Results link to source documents for employee review. It is available to Team and Enterprise customers. It does not control physical machines yet.
