Codex CLI 0.170.0 Released with WebRTC Voice and Bug Fixes

Codex CLI version 0.170.0 adds WebRTC voice call negotiation, OpenTelemetry header refreshes, and various bug fixes.

Codex CLI version 0.170.0 introduces WebRTC negotiation for realtime voice calls in the terminal user interface. The release adds automatically refreshed authentication headers for OpenTelemetry HTTP exporters and experimental support for identically named MCP servers across environments. Bug fixes address oversized WebSocket requests falling back to HTTP, MCP OAuth credential races, automatic reconnection for Cloud conversations, Windows file replacements, sandbox permission preservation, runtime registration recovery, and duplicate file search results.
