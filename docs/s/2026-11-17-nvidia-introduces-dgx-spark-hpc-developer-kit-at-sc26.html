NVIDIA Introduces DGX Spark HPC Developer Kit at SC26

NVIDIA introduced the DGX Spark HPC Developer Kit at SC26, bringing a four-node cluster with the GB10 Grace Blackwell Superchip to desktops.

At the SC26 conference in Chicago, NVIDIA introduced the DGX Spark HPC Developer Kit for researchers, academics, and developers. The kit is a four-node cluster of NVIDIA DGX Spark systems connected in a ring over NVIDIA ConnectX-7 networking, with no network switch required. It provides 512GB of combined memory, 20TB of NVMe storage, and uses the GB10 Grace Blackwell Superchip. The system allows researchers to run multi-node scientific workloads, AI models, and agents locally, bypassing shared cluster queue times. Partners such as Dell, HP, Lenovo, and ASUS offer the hardware.
