NVIDIA says Vera CPU beats top x86 chips on agent speed and efficiency

NVIDIA says its Vera CPU gives 1.6x more agents per watt than the fastest x86 CPU and 2x faster agent speed than the most efficient one.

NVIDIA published results for its Vera CPU, aimed at AI agent workloads in power-limited AI factories. In a 100-megawatt data center comparison, NVIDIA says Vera delivers 1.6x more agents per watt than the fastest x86 CPU. It also says Vera gives 2x faster agent speed than the most energy-efficient x86 CPU. Partners reported tests too. Perplexity ran agentic coding tasks 1.5x faster. DeepInfra saw up to 2.2x the speed of the best x86 processor. Daytona brought 1,000 agent sandboxes online in 10.8 seconds versus 88.4 seconds with x86. Modal reported up to 2x sandbox throughput per core.

Imagine a kitchen where many helpers each need a stove to cook. Vera is a stove that heats up fast and also lets many helpers cook at once without using much power.

Why it matters

Teams running many agents may be able to use one CPU type for both speed and capacity, which matters when power is the limit.
