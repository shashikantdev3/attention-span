Meta releases Muse Spark Open model in Amazon SageMaker JumpStart

Meta's coding-optimized open-weight model, Muse Spark Open, is now available in Amazon SageMaker JumpStart.

Meta released Muse Spark Open, an open-weight frontier multimodal mixture-of-experts model. The coding-optimized model is now available in Amazon SageMaker JumpStart. It was trained on real developer workflows, including multi-file refactors and long debugging sessions. It supports a context window of 1 million tokens. The model uses a mixture-of-experts architecture with 816 billion total parameters, with 42 billion active for each token. It accepts text, images, documents, audio, and audio-video as input and returns text. Amazon SageMaker JumpStart offers BF16 and NVFP4 quantized variants. Meta releases the weights under the Muse Model License.
