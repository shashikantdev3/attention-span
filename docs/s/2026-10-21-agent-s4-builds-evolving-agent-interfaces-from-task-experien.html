Agent S4 Builds Evolving Agent Interfaces From Task Experience

Researchers introduce Agent S4, an autonomous computer-use scientist that builds evolving agent interfaces from task experience to improve efficiency and performance.

Computer-use agents are limited by hand-built interfaces and knowledge. Researchers argue that interface design should be an agent capability. They introduce Agent S4, an autonomous computer-use scientist that builds Evolving Agent Interfaces from task experience. A meta-agent examines task agent trajectories on synthetic training tasks, without success labels, and constructs and revises interfaces and usage knowledge in a repository. Population-based evolution then selects repositories by their performance on validation tasks. On OSWorld V2, Agent S4 with Qwen3.8-27B reaches a 21.3% binary score, beating GPT-5.5 and Claude Opus 4.8 at lower costs.

Just like teaching a toy robot to build its own better tools instead of giving it fixed ones, Agent S4 creates and improves its own software interfaces to do computer tasks better.

Why it matters

Autonomous interface design improves computer-use agent performance beyond fixed human-built limits.
