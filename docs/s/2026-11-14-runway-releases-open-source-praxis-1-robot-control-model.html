Runway Releases Open Source Praxis 1 Robot Control Model

Runway has released its Praxis 1 robot model with open weights and source code under the Apache 2.0 license.

Runway has released its Praxis 1 robot model with open weights and source code under the Apache 2.0 license. Praxis 1 takes in camera images, text instructions, and robot position data to calculate matching robot movements. The model builds on video training that learned how objects move from ordinary footage, then was fine tuned with human action videos and robot data. On Nvidia's RoboLab 120 leaderboard, Praxis 1 achieves a 46.2 percent success rate, placing it at the top of the World Action Model category. The standard version requires an 80 GB GPU, while a compressed version may fit on an RTX 5090 with 32 GB of VRAM.
