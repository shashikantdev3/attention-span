Custom SQL Pools in Microsoft Fabric Data Warehouse Generally Available

Custom SQL Pools and statement type classification are now generally available in Microsoft Fabric Data Warehouse.

Custom SQL Pools and statement type classification are now generally available in Microsoft Fabric Data Warehouse. Administrators receive more control over compute resource allocation across different workloads in a workspace. Workloads can be isolated into separate pools, and maximum resource allocation percentages can be set. Statement type classification separates read and write workloads into SELECT and NONSELECT categories. Fabric creates separate pools for both categories with an initial maximum allocation of 50 percent each. Administrators can adjust these percentages as long as the combined maximum allocation does not exceed 100 percent.
