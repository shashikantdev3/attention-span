nanoMuse Offers Open-Source Personal Agent

A new open-source personal agent called nanoMuse provides an alternative to closed vendor systems.

Meta introduced Muse in September 2026 as a closed personal agent in a vendor cloud. Until now, such personal agents had no open counterpart. Researchers have now introduced nanoMuse under the GPL-3.0 license. This open-source personal agent runs on every device a person owns. It uses a shared conversation over a relay, actions through a Sentinel, and readable files for memory. The user chooses the model, and its size and cost are given as estimates.

Imagine a helper robot that lives on all your devices and remembers everything you tell it. Before, only one company made this robot in a locked room, but now anyone can build and share their own version.

Why it matters

Building with personal agents is now possible using an open-source option instead of relying on closed vendor clouds.
