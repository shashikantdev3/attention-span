Microsoft Announces New Capabilities in Microsoft Fabric at Ignite 2026

Microsoft introduced new Microsoft Fabric features at Ignite 2026, bringing application development, operational databases, and analytics closer together.

At Microsoft Ignite, Microsoft announced new capabilities in Microsoft Fabric to help teams build and operate intelligent applications with less complexity. The announcements include Fabric apps in general availability using the Rayfin SDK and CLI, Microsoft Fabric HorizonDB in preview to bring serverless PostgreSQL to Fabric, and Database Hub in general availability with database agents for SQL and PostgreSQL in preview. Additionally, Microsoft reported that more than 44,000 paid customers now use Microsoft Fabric, and more than 19,000 customers use Microsoft Foundry and Fabric together.
