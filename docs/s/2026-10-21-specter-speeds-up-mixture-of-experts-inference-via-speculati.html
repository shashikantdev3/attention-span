Specter Speeds Up Mixture-of-Experts Inference via Speculative Offloading

Specter uses quantization and speculative offloading to reduce PCIe bottlenecks and speed up mixture-of-experts model inference on commodity hardware.

Mixture-of-experts models often exceed single accelerator memory capacity. Offloading experts to host memory creates a severe PCIe I/O bottleneck because data-dependent routing keeps transfers on the critical path. Researchers presented Specter, an inference system that uses quantization to combine speculative decoding with expert offloading. Its lightweight quantized draft model runs efficiently on device while preserving high-fidelity expert activation patterns. This provides accurate multi-step lookahead over future expert usage, allowing the runtime to organize expert movement and execution ahead of verification. Under single-request inference, Specter achieves an average 1.50x speedup in time per output token over the state-of-the-art system.
