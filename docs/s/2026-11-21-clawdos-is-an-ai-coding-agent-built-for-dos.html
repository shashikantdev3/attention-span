ClawDOS is an AI coding agent built for DOS

ClawDOS is an AI coding agent that runs on an IBM PC XT with an 8088 processor and DOS.

ClawDOS is an AI coding agent that runs on an IBM PC XT with an 8088 processor at 4.77 MHz, 640K of RAM, and a CGA card. The harness runs natively on the hardware and uses a bridge PC to handle TLS. The program speaks the Claude Messages API itself, reading and editing files on the disk, writing programs, compiling them with Turbo C, running them, and looking at the screen. It features eighteen tools, safe mode by default, and persistent disk-based conversations.

It is like teaching an advanced helper robot to write computer programs using a very old computer from the 1980s.

Why it matters

Running autonomous agents on vintage hardware proves that modern AI workflows can operate under extreme computational constraints.
