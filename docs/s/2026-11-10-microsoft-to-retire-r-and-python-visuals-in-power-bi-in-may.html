Microsoft to retire R and Python visuals in Power BI in May 2027

Microsoft will retire the built-in R and Python visuals in Power BI in May 2027, and reports using them must be rebuilt with other visuals.

The Power BI Blog says the built-in R and Python visuals in Power BI will retire in May 2027. The change applies only to visuals in interactive reports. Python scripts in Power Query that populate tables are not affected. In the Power BI service, these visuals will stop working in published reports, and R-powered custom visuals will stop too. Older versions of Power BI Desktop keep working locally with R and Python installed. Future Desktop versions will remove the visuals. No migration will recreate an exact visual, so teams must replace each one with a different visualization before retirement.
