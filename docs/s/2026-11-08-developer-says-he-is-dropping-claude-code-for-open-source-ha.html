Developer says he is dropping Claude Code for open source harness Pi

A developer blog post says he has moved from Claude Code to Pi, citing IDE bugs, frequent system prompt changes and token overhead.

In a blog post dated 21 September 2026, a longtime Claude Code user says he is retiring it as his main coding harness and moving to Pi. He cites many small frustrations. Only one session can connect to the IDE at a time, and the VSCode GUI extension has broken slash commands. He says there have been 244 Claude Code releases this year, and over 3/4 changed the system prompt or tool descriptions. He says the default Bash tool description is almost 3,000 tokens. He praises Pi for stability, a minimalist approach and customizability.

Imagine a toy box that keeps getting new gadgets stuck on it, and some of them break. The writer picked a simpler toy box that does less but works the way he likes.

Why it matters

Frequent system prompt changes and large default tool descriptions can change how a coding agent behaves and how many tokens it uses, so a small, customizable open source harness may suit teams who want stability.
