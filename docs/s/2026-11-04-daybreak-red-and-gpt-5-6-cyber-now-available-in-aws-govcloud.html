OpenAI's Daybreak Red brings GPT-5.6 Cyber to approved customers on AWS GovCloud

Daybreak Red is now available in AWS GovCloud, bringing GPT-5.6 Cyber to approved government customers through Amazon Bedrock.

On November 4, 2026, OpenAI announced that Daybreak Red is now available in AWS GovCloud, US-East. This expansion brings GPT-5.6 Cyber to approved customers through Amazon Bedrock. Government security teams can now apply advanced cybersecurity capabilities within their established AWS environments. Daybreak Red provides access to purpose-trained cybersecurity models for authorized vulnerability research, exploit validation, and security testing. Qualified security practitioners should review findings and proposed fixes before implementation. Inference data is not used to train models, and customers do not need to share data with OpenAI. Access requires Daybreak Red approval and AWS provisioning.
