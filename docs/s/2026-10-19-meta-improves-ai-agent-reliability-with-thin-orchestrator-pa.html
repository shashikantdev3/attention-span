Meta Improves AI Agent Reliability With Thin Orchestrator Pattern

Meta improved AI agent reliability by using a thin orchestrator router that performs zero domain work and delegates to specialized subagents.

Meta built a 1,300-line orchestrator that routes over 20 workflows to 14 specialized AI agents while performing zero domain work itself. When automating data column onboarding across recommendation systems, a single smart agent that knew everything began to hallucinate in production due to context overload. The new thin orchestrator pattern uses a deterministic router that handles sequencing and reliability checks. It leaves every domain decision to specialized subagents with isolated contexts. This approach prevents context interference and allows teams to support new use cases by writing new workflow templates that reuse existing agents.
