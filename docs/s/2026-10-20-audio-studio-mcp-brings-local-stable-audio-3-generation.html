Audio Studio MCP Brings Local Stable Audio 3 Generation

A new Model Context Protocol server lets AI clients generate local background music and sound effects using Stable Audio 3.

Audio Studio MCP is a local project that gives Claude Code, Claude Desktop, Cursor, and any Model Context Protocol client a sound studio running on a local Mac or Windows PC. It uses Stable Audio 3 to generate background music and sound effects locally without any cloud service or API key. On Apple Silicon, it uses MLX. On Windows NVIDIA GPUs, it uses PyTorch. The server handles prompting, looping, loudness normalization, and file export for game engines or video editors. Every generated file includes a json sidecar with the prompt, seed, and settings.
