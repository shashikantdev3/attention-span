Google Announces Gemini Decisions API and Gemini Decision 1 Model

Google launched the Gemini Decisions API, powered by the Gemini Decision 1 model, to evaluate up to 1,000 questions in a single pass.

Google introduced the Gemini Decisions API powered by the Gemini Decision 1 model. The tool evaluates up to 1,000 yes/no, choice, and rubric-scoring questions in a single pass across text, images, audio, video, and PDFs. It computes confidence scores with an end-to-end latency of 150 to 250 ms at $0.10 per 1M input tokens with zero output tokens billed. The model supports contexts up to 256K tokens. Teams across Google use the API for dynamic model routing, rapid design iteration, emoji selection, and safety checks.

It is like having a helper look at a picture and answer a thousand multiple-choice questions about it all at once, instead of writing out long answers one word at a time.

Why it matters

Evaluates multiple questions across multimodal inputs in a single forward pass without generating text token by token.
