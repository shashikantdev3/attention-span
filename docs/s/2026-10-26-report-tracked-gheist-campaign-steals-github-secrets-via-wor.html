Wiz tracks Gheist, a campaign using stolen GitHub tokens to steal repository secrets

Wiz Research tracked the Gheist campaign, which abuses stolen GitHub tokens to plant secret-dumping workflows in private repositories.

Since September 15, 2026, Wiz Research has tracked the Gheist campaign. The attack performs mass abuse of compromised GitHub tokens by committing a workflow named sync-check to repositories. The workflow prints repository secrets in base32 encoding into its own log. The tool then downloads the log through the GitHub API and deletes the run. The campaign has affected more than 850 compromised accounts and planted over 13,500 branches. While GitHub controls block public repository exploitation, private repositories and enterprise environments remain vulnerable to the ongoing attack.
