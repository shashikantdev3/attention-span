Apple's Foundation Models framework adds server models, Dynamic Profiles, image input and an fm CLI

Apple's Foundation Models framework now reaches server models like Claude and Gemini through one Swift API, and adds Dynamic Profiles, image understanding, Evaluations and an fm command line tool.

Apple describes the Foundation Models framework as a native Swift API for using large language models in apps. It gives direct access to Apple Foundation Models on-device and in Private Cloud Compute. It now extends to server models like Claude and Gemini through the same API. Model providers can ship a Swift package that conforms to the Language Model protocol. New pieces include Dynamic Profiles, image understanding, an Evaluations framework, and the fm command line tool in macOS 27. Open source options include a utilities package and a Python SDK.

Why it matters

One Swift API now covers on-device, Private Cloud Compute and third-party server models, so swapping models in an Apple app needs less rewriting, and the Evaluations framework offers a way to test prompts before shipping.
