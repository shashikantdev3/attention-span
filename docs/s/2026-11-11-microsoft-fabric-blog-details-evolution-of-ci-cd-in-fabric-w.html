Microsoft Fabric Blog Details Evolution of CI/CD in Fabric Warehouse

Microsoft Fabric is evolving CI/CD for Fabric Warehouse to support software engineering practices like Git versioning and automated deployments.

Building and operating a data warehouse is increasingly a software engineering discipline. Teams want to develop warehouse changes in isolation, version them in Git, review them through pull requests, promote them safely across environments, and automate the entire process using existing CI/CD systems. Over recent releases, CI/CD in Fabric Warehouse has evolved around this lifecycle. DacFx established a common schema deployment foundation. Pre and post-deployment scripts expanded deployments beyond schema changes. Warehouse Item Definition APIs opened the same lifecycle to automation, creating a more complete CI/CD lifecycle from developing database changes to deploying them.
