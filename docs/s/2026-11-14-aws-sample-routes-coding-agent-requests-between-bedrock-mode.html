AWS sample routes coding agent requests between Bedrock models using NVIDIA NeMo Switchyard

AWS published a sample that deploys LiteLLM with the NVIDIA NeMo Switchyard plugin on Amazon Bedrock to route coding agent requests and measure cost per solved task.

An AWS Machine Learning Blog post shows how to deploy LiteLLM with the Switchyard routing plugin using the AWS CDK. LiteLLM calls models on Amazon Bedrock. Switchyard offers Stage routing, which picks between two candidate models, and Random routing, which splits traffic by weight. The post says to judge routing by cost per solved task: total run cost divided by runs whose tests pass. The sample includes benchmark runners to compare a routed group with single-model baselines. It installs switchyard-server 0.3.0 and runs LiteLLM v1.102.0. It is experimental sample code for non-production use.

Like I am 5

Imagine you have a big helper and a small helper for chores. You send easy chores to the small helper and hard chores to the big one. Then you count how much it cost for each chore that got finished.

Why it matters

Routing coding agent calls between a capable model and a cheaper one can be judged by cost per solved task, which gives teams a clearer way to compare routing against single-model setups on their own workloads.
