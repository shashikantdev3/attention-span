SGLang-Neuron brings SGLang serving to AWS Trainium via Deep Learning Container

Amazon says SGLang-Neuron is publicly available, letting developers serve models and run RL rollouts with SGLang on AWS Trainium through a Deep Learning Container.

Amazon announced that SGLang-Neuron is publicly available through an AWS Deep Learning Container. RadixArk released it with Annapurna Labs. You can serve models and generate reinforcement learning (RL) rollouts with SGLang on AWS Trainium using the same SGLang interface. It is an out-of-tree plugin that runs on native PyTorch. SGLang core keeps the API server, request lifecycle, RadixAttention and prefix-cache bookkeeping. The plugin handles Trainium-specific models, attention, mixture of experts (MoE) and the graph runner. It also supports PD disaggregation, using NIXL over Elastic Fabric Adapter (EFA). The walkthrough serves openai/gpt-oss-120b on a Trainium3 EC2 instance.

Why it matters

Teams already serving models with SGLang can try AWS Trainium chips without changing their server interface or generation APIs.
