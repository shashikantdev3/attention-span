StarSling Launches Self-Improving CI for Agent-Volume Repositories

Yonas and Daniel launched StarSling, which provides fast GitHub Actions runners with AI agents that ship pull requests to improve tests.

Yonas and Daniel built StarSling to provide fast GitHub Actions runners with AI agents. These agents ship pull requests to continuously improve tests and workflows. Each CI job runs in its own ephemeral sandbox on Zen 5 machines and NVMe disk with unlimited concurrency. Mastra merged over 1,800 pull requests a month and reduced its slowest workflow from 29 minutes and 56 seconds down to 5 minutes and 6 seconds on StarSling. The company supports per-second billing and offers StarSling Disks for persistence. Founders previously founded StackShare and helped build Netflix's internal developer portal.

Why it matters

Autonomous code generation requires specialized runner infrastructure to handle high volumes of pull requests without breaking the CI budget.
