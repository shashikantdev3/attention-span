New Project Lets AI Models Control Real iPhones Using ESP32

A new project allows any OpenAI-compatible vision model to control a real iPhone using a seven dollar ESP32 board without a Mac.

The esp32-iphone-agent project allows artificial intelligence models to interact with a physical iPhone using a seven dollar ESP32-S3 board and AirPlay screen mirroring. The setup requires no Mac, developer account, or jailbreak. AirPlay streams the phone screen to a computer running UxPlay, which converts the stream into JPEG frames for the vision model. The ESP32 plugs into the phone USB port as a mouse and keyboard to execute taps and swipes using iOS AssistiveTouch. A planner model creates plans based on goals and screenshots, while an actor model selects subsequent actions.
