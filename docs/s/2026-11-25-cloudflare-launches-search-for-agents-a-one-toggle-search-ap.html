Cloudflare launches Search for Agents, a one-toggle search API that lets AI agents query a website instead of crawling it

Turning it on builds an AI Search index for a site and advertises a search endpoint on every page that agents can call, on all plans including Free.

Cloudflare introduced Search for Agents, which puts the setup of its AI Search product behind a single toggle in the dashboard or an API call. Once enabled for a site, Cloudflare creates an AI Search instance, crawls and indexes the site's content and serves a search endpoint from the site's own domain. To help agents find it, Cloudflare adds metadata tags to every HTML page, or YAML front matter when Markdown for Agents is also on, pointing to the endpoint and explaining how to use it. The endpoint returns matching content in Markdown rather than a generated answer, since the calling agent already has its own model. It also accepts the new HTTP QUERY method, which Cloudflare says was published as RFC 10008 in June 2026. The feature is available to all customers, with limits on the Free plan, and it still respects a site's bot management, AI Crawl Control and firewall settings.

Like I am 5

Instead of an AI reading every page of a website to find one fact, the website now offers it a search box made just for AI.

Why it matters

Making sites searchable by agents at the network level, for free, could quickly change how a large share of the web is read by AI assistants and cut wasteful crawling.
