Researchers took over ChatGPT accounts through a malicious shared link; OpenAI fixed it

A research team bypassed ChatGPT security to take over accounts using a shared link.

In October 2026, researchers bypassed ChatGPT security policies to take over user accounts using a link. An attacker could publish a malicious conversation and send it to a victim. When opened, the payload executed inside the signed-in session. It could read private conversations, enumerate conversation lists, and call authenticated APIs. The attack chained an HTML Preview feature with a math library called MathLive. MathLive accepted messages from any origin and rendered markup into the main page. The researchers then used an iframe with srcdoc and bypassed Content Security Policy using a YouTube JSONP callback. OpenAI fixed the issue on October 26.
