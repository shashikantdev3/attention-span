Mistral AI launches Voxtral 3 voice agent stack

Mistral AI introduced Voxtral 3, a voice agent stack featuring speech-to-text, text-to-speech, and a voice agent SDK supporting over 50 languages.

Mistral AI has launched Voxtral 3, a new family of speech-to-text and text-to-speech models alongside a voice agent SDK. The system combines listening, reasoning, tool calling, and speaking into a single real-time streaming pipeline. It supports over 50 languages, including 24 official EU languages and various low-resource Asian and Indic languages. The stack includes Voxtral Small Transcribe 3 for multilingual transcription and diarization, and Voxtral Mini TTS 3 for emotional text-to-speech. Available via Mistral's EU-hosted API or self-deployment, Voxtral 3 enables low-latency voice interactions for contact centers and virtual assistants while maintaining data sovereignty.
