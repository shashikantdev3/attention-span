Kimi K3.1 Pro Highspeed from Moonshot AI now available on Amazon Bedrock

Moonshot AI's Kimi K3.1 Pro Highspeed is now on Amazon Bedrock, with Moonshot AI reporting 2–3 times the speed of Kimi K3.1 Pro.

Kimi K3.1 Pro Highspeed from Moonshot AI is now on Amazon Bedrock. It is a post-trained version of Kimi K3 with the same 3T-class open-weight architecture and 1-million-token context window. Moonshot AI says the extra post-training targets long-horizon agentic work and fewer factual errors. Moonshot AI also reports 2–3 times the speed of Kimi K3.1 Pro. It uses the same endpoint, APIs and features as Kimi K3, so existing Kimi K3 users can try it by changing the model ID. It supports tool calling, structured output, configurable reasoning, image input and streaming. The Flex tier costs half the Standard price.
