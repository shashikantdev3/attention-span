Browser Automation Tool in Microsoft Foundry is Now GA

Microsoft Foundry has made its browser automation tool generally available, giving AI agents a managed browser to navigate websites using natural language.

The browser automation tool in Microsoft Foundry is now generally available. It provides agents with a managed browser powered by Playwright Workspaces. Agents can navigate websites, inspect content, complete forms, and perform multistep workflows using natural-language instructions. The tool supports prompt agents, hosted agents, and GitHub copilot harness support. Agents interact through an observe-and-act process. They can connect to both public websites and private applications protected behind an Azure virtual network. The architecture includes native remote Model Context Protocol integration, centralized identity and connection management, and tool allow lists.
