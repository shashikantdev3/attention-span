Microsoft Fabric Announces Salesforce Data 360 Integration in Preview

Salesforce Data 360 integration with OneLake is now available in preview, allowing zero-copy file sharing for analytics.

Organizations can now use OneLake Shortcuts to make Salesforce Data 360 data available in Microsoft Fabric and query them alongside enterprise data. Salesforce Data 360 remains the source of the data, while Microsoft OneLake brings the analysis together. These shortcuts reference the data in Salesforce Data 360 instead of importing a separate copy into the lakehouse. The data stays current without needing extra refreshes. This avoids exporting customer data, building ingestion pipelines, and maintaining duplicate copies for analytics.
