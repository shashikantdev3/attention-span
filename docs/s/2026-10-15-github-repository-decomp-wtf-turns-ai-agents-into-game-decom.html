GitHub repository decomp.wtf turns AI agents into game decompilers

A new tool named decomp.wtf allows AI agents to decompile owned games into C code that compiles to exact byte matches.

The decomp.wtf repository provides a local tool that lets AI agents decompile games owned by users into C code that compiles to the exact same bytes. It supports platforms including Nintendo 64, PlayStation 1 and 2, GameCube, Wii, Game Boy Advance, and DS. The application runs locally on Linux and Windows using WSL 2 without accounts or telemetry. Agents work function by function, testing attempts with original compilers and byte-for-byte judges. Users can start projects from scratch or continue community decomps from decomp.dev. It also integrates with existing tools through an MCP server.
