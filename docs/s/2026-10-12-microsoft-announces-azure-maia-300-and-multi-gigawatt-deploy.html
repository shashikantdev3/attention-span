Microsoft Announces Azure Maia 300 and Multi-Gigawatt Deployments

Microsoft plans multi-gigawatt deployments of its Azure Maia chips starting in 2027, introducing the Maia 300 system.

Microsoft announced plans to scale its Azure Maia family to multi-gigawatt deployments starting in 2027. The Maia 200 is currently in production, serving workloads like Microsoft Copilot and running OpenAI models, Microsoft MAI models, and open-source models. GitHub Copilot and Microsoft Foundry will use Maia 200 by the end of the year. Meanwhile, Maia 300 is coming in 2027 as a complete intelligent system for long-context reasoning, latency-sensitive conversational experiences, and multi-step agentic tasks. Maia 300 will deliver 40% more tokens per megawatt compared to leading GPU-based systems and features a multi-chiplet architecture.
