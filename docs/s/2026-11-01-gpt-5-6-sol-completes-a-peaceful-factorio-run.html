GPT-5.6 Sol completes a peaceful Factorio run

An AI model completed a peaceful run of Factorio in 13.5 hours of game time.

GPT-5.6 Sol, running in Codex with low thinking level, completed a peaceful Factorio run without biters in 13.5 hours of game time. A game manager used a Python library to let the model interact with the game programmatically under human GUI restrictions like reach and fog of war. The run progressed past blue science research, though scaling issues slowed progress later. Sol achieved the rocket launch by using manual effort to ferry supplies between factory areas, showing an improvement over GPT-5.5.
