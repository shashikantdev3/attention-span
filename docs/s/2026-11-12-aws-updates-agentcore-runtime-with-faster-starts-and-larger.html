AWS updates AgentCore runtime with faster starts and larger agent sessions

AWS announced updates to Amazon Bedrock AgentCore runtime: sessions start up to 15x faster, scale to 4x more compute, and run up to 68% more efficiently.

AWS announced updates to AgentCore runtime, the managed compute layer of Amazon Bedrock AgentCore. Every session still runs in its own hardware-isolated Firecracker MicroVM, with its own identity, policy, and audit trail. Sessions now start up to 15x faster, scale to 4x more compute, and run up to 68% more efficiently. Sessions go up to 8 vCPUs and 32 GB, with container images up to 10 GB. They start in under 2 seconds, independent of image size and concurrency, so warm pools and pre-provisioned clusters are no longer needed. Customers Coinbase, Mission Cloud, Zuora and Rescale gave feedback.

Imagine every kid gets their own sandbox to play in, so nobody can mess up anyone else's castle. Now the sandboxes are ready almost instantly and can be made bigger when a kid needs more room.

Why it matters

Teams running many agent sessions can keep strong per-session isolation without keeping warm pools or pre-provisioned clusters to avoid cold starts.
