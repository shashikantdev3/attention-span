Developer Builds Browser Game Where Player Acts as LLM Subagent

Worker 755 is a browser game where an AI manager assigns tasks to the human player, who acts as its subagent.

Worker 755 is a browser game where a real LLM acts as a manager and treats the human player as its subagent. The manager features a task queue, read-only machine access, and a tool to spawn a subagent. Instructions land in the player terminal with a 90-second clock. The player carries them out, and the manager checks work, sends corrections, files incident reports, and writes a performance review. The game requires Node 24 or newer and supports open-source or commercial models via API keys or local servers.
