SparseDecoding Proposes Decoding-Aware Pruning for LLM Inference

SparseDecoding is a decoding-aware pruning framework designed to improve accurate and efficient large language model inference.

Large language model inference suffers from significant latency during the decoding stage because of its memory-bound nature. Layer-wise training-free network pruning guided by the Hessian is a known solution, but typical methods compute the Hessian using pre-collected natural sequences. This creates a distribution shift from self-generated tokens. SparseDecoding addresses this by constructing calibration matrices from layer-wise activations collected during dense-model autoregressive generation, excluding prefill. This aligns the pruning objective with decoding activations.

Like I am 5

Pruning a language model is like trimming unneeded branches off a tree to make it lighter, and SparseDecoding makes sure you trim the right parts by watching how the tree actually grows.

Why it matters

Aligning pruning objectives with actual decoding activations reduces performance loss during efficient large language model inference.
