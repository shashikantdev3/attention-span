Microsoft Details Audit of Coding Benchmarks

Microsoft shares its iterative auditing process for coding benchmarks like DeepSWE and Terminal-Bench 4.0, identifying defects and improving evaluation reliability.

Microsoft audited coding benchmarks, specifically DeepSWE and Terminal-Bench 4.0. The audit identified benchmark quality issues across 12 DeepSWE tasks and 10 Terminal-Bench 4.0 tasks. These issues included task ambiguity, evaluability problems, grader design issues, and evaluation environment failures. Instead of aggressively filtering out every task with a defect, Microsoft assesses the likelihood of a defect manifesting and its material impact. The team submitted fixes where no pull requests were available and joined syncs with maintainers to collaborate on improvements.
