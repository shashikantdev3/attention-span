Microsoft Fabric adds Iceberg REST Catalog writes to OneLake

Microsoft Fabric now supports Iceberg REST Catalog writes, while a new metadata API for adding descriptions and tags is available in preview.

Microsoft Fabric has updated its OneLake table APIs to support Iceberg REST Catalog writes. This allows engines like PyIceberg, Snowflake, and DuckDB to create native Iceberg tables, commit snapshots, and request storage credentials directly in OneLake. These operations do not require custom connectors or copy jobs. Additionally, a new table metadata API is available in preview. This feature allows users to add descriptions and tags to tables and columns. These updates enable engines to publish data and provide business context for people and AI agents.
