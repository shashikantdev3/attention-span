PostHog Shares Production Use Cases for Decision Models

PostHog uses decision models to gate expensive LLM calls, route requests to cheaper models, and perform face-value checks.

PostHog experiments with decision models for simpler tasks to avoid expensive large language model calls. Decision models return typed answers with explicit probabilities. PostHog uses them as gates in pipelines to remove personal information, reducing LLM calls because 98.7% skip the LLM call entirely. They also act as model routers to pick the cheapest model that can finish a task. Additionally, decision models perform face-value checks on pre-processed inputs, such as evaluating search result matches, which improved ranking quality by about 25% on test queries.

Like I am 5

Instead of asking a super smart and expensive expert every time you have a tiny question, you use a quick sorting tool to handle the easy stuff first.

Why it matters

Filtering and routing workloads through smaller decision models lowers processing costs and speeds up execution before engaging expensive large language models.
