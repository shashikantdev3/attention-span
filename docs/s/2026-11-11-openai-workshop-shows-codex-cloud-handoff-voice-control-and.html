OpenAI workshop shows Codex cloud handoff, voice control and personal agents

At the AI Engineer Code Summit, OpenAI engineers showed how Codex now blends local and cloud work, uses voice, and pairs with personal agents called dots.

OpenAI hosted a workshop called "New Ways of Working with Codex" at the AI Engineer Code Summit. Developer Experience engineers Dominik Kundel and Charlie Guo led it. Codex launched in May 2025 as a cloud-based agent for parallel tasks. Codex Cloud version 2 was announced after DevDay in late September. You publish an environment once and run multiple tasks in isolated instances. Kundel said local and cloud Codex are "merging together" and that he asks Codex to push a branch and start a cloud thread. Guo uses voice as a control plane. He said dots feel a little awkward to work with as a Codex power user.

Like I am 5

Think of a helper who can work at your desk or in another room, and you can talk to them or write notes. The workshop showed how to switch between these ways of working.

Why it matters

Moving a task between local and cloud Codex, and steering it by voice, may reduce friction in daily coding, though OpenAI says the cloud handoff still needs to get easier.
