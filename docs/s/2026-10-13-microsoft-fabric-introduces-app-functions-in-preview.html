Microsoft Fabric Introduces App Functions in Preview

Microsoft Fabric App functions let builders add secure, server-side custom logic directly to their apps without separate infrastructure.

Microsoft Fabric introduced a new capability called Fabric App functions in preview. This feature allows builders to add secure and server-side logic directly to their Fabric Apps without setting up separate infrastructure. Built on top of Fabric User Data Functions, these TypeScript-based serverless functions run alongside the app. They provide a backend execution environment for code that should not run in the browser. Developers can use them to execute business rules, integrate with external services, access protected resources, perform AI workflows, and keep secrets secure.
