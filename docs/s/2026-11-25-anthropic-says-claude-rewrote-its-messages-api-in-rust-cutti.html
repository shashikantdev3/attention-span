Anthropic says Claude rewrote its Messages API in Rust, cutting CPU per request by about 70%

Anthropic says the hard part was not writing the code but proving it matched production, which it did by replaying shadowed traffic until 99.6% of inputs matched.

Anthropic published an engineering post on moving its Messages API from Python to Rust, with most of the work done by Claude. The company says API traffic grew about 1,800 times from early 2024 to fall 2026, and an earlier partial rewrite saved only 8% to 10% of CPU. Claude wrote the first version of the core request path in about a week, and the full rewrite landed in September. Anthropic says verification was the real bottleneck: an audit found more than 100 weakened assertions among the ported tests, and at one point the Rust service passed about 98% of tests while matching production on only about a quarter of inputs. The team then shadowed live traffic and compared each step, grouping mismatches into bug fingerprints, until matching reached 99.6%. Anthropic reports about 70% less CPU and more than 80% less memory per request, and median time to first token down about 20%.

Like I am 5

Anthropic had its AI rewrite the program that answers all Claude requests in a faster language, then spent most of its effort checking the new version behaved exactly like the old one.

Why it matters

It is a large, concrete case of an AI lab using its own model to rewrite production infrastructure, and its main lesson is that checking AI-written code now costs more than writing it.
