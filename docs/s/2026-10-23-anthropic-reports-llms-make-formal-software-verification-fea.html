Anthropic Reports LLMs Make Formal Software Verification Feasible

Anthropic and Theorem used Claude to produce formal correctness proofs for over 100 open-source software libraries.

Anthropic and Theorem used Claude to produce formal correctness proofs for 123 open-source libraries at the assembly code level on RISC-V. Claude proved specific security properties, such as exiting normally without memory safety errors or failed assertions, under stated assumptions including inputs under 64 MB and single-threaded static binaries. While writing the proofs, Claude discovered bugs that had eluded detection for years. Formal verification previously required years of expert effort, making it impractical for most real-world projects.
