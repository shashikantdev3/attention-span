Cloudflare details a cross-customer KV cache exposure in its GLM-5.3 service

A security bug in the GLM-5.3 Workers AI model caused 155 responses to contain data from other customers' requests.

On September 8, 2026, Cloudflare was alerted to a tenant isolation issue affecting the GLM-5.3 Workers AI model. Between August 27 and September 9, a small number of customers using prompts longer than 681,280 tokens received responses containing data from other users. The issue stemmed from a configuration mismatch where the context window exceeded the prefill GPU pool size, combined with a bug in the SGLang inference engine that mishandled over-length requests in disaggregated mode. Cloudflare disabled the model, adjusted configurations to hold the full context, patched the inference engine, and restored service on September 9.
