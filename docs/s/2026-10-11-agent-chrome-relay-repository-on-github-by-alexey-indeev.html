Agent Chrome Relay Repository on GitHub by Alexey Indeev

Alexey Indeev created a GitHub repository for agent-chrome-relay, letting coding agents use Chrome in background tabs.

Alexey Indeev published agent-chrome-relay on GitHub. The tool lets coding agents like Claude Code, Codex, Cursor, and Paseo use everyday Google Chrome through the command line in background tabs. It runs at approximately 0.15s per command without taking focus or showing dialogs. The setup requires macOS, Google Chrome, Go 1.25+, and agent-browser. It features an audit trail, background tabs, and optional integrations with 1Password and Secure Enclave passkeys. The repository has 251 stars and uses the Go language.

Like I am 5

It is like giving your robot assistant its own invisible browser window so it can look up things for you without taking over your screen.

Why it matters

Coding agents can perform browser tasks directly in the background using existing user logins and session states.
