Microsoft Foundry Introduces Trusted Autonomous Agents for Teams

Microsoft Foundry lets enterprises build autonomous agents with their own Microsoft Entra identities, user accounts, and managers.

Microsoft Foundry now allows organizations to build autonomous AI agents that work alongside teams in Microsoft 365. Unlike single-user personal assistants that borrow user credentials, these agents have their own Microsoft Entra agent identity and user account. This setup provides each agent with its own email, calendar, OneDrive, Teams presence, and accountable manager. Enterprises build an agent blueprint as a service, which admins approve. Approved users then hire individual instances with specific resource access, separating agent capability from specific team resource permissions.

Like I am 5

Instead of an AI pretending to be you using your password, it gets its own employee badge, email address, and office desk so everyone knows exactly who did the work.

Why it matters

Autonomous agents gain distinct enterprise identities and audit trails, solving the permission and governance problems that keep multi-user workflows single-player.
