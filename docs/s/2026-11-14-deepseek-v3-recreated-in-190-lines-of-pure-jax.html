DeepSeek V3 Recreated in 190 Lines of Pure JAX

A developer created the DeepSeek V3 architecture in 190 lines of pure JAX, pretrained from scratch on a MacBook Air.

An implementation of the DeepSeek V3 architecture in 190 lines of pure JAX has been released on GitHub. Pretrained from scratch on a MacBook Air using public domain detective fiction, the model uses plain dictionaries of arrays without Flax, Equinox, or PyTorch. The project includes setup scripts, data preparation tools, a tokenizer, training scripts, and sampling utilities. It uses a simplified dense mixture of experts approach and explicitly decompresses latents. The model contains 36.2 million parameters across 6 layers with a 256-token context window.
