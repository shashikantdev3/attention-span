Meta Uses Idle AI Inference Capacity to Improve Ads

Meta built a system that turns idle AI inference capacity into better ads recommendations without compromising baseline performance.

Meta built a system that aggregates locally idle pockets of AI inference capacity into a shared pool. The system improves ads recommendations by putting otherwise wasted capacity to work. Inference fleets often face a capacity paradox where they are globally constrained while remaining locally idle due to demand mismatches, timing gaps, or hardware differences. Meta uses two levers to handle this volatile capacity safely. Rank More Ads adjusts the number of candidates evaluated in ranking stages. Serve Better Models adjusts the share of requests routed to more powerful models. These mechanisms expand and contract optional work while protecting baseline reliability.

Like using extra empty seats on a bus to let more people on when they are waiting, the system uses extra computer power that is sitting around to show better ads.

Why it matters

Idle hardware across distributed inference fleets can be harnessed dynamically for heavy workloads using elasticity levers and isolated control loops.
