An engineer went from 8 to 20 pull requests a month to over 200 at an AI-native startup (The Pragmatic Engineer)

Software engineer Neil Kakkar won an essay challenge detailing how joining an AI-native startup increased his pull request output tenfold.

Software engineer Neil Kakkar won an essay challenge hosted by The Pragmatic Engineer, which received 125 submissions. Kakkar, who has nine years of professional experience, compared his software output across three workplaces: Bloomberg, PostHog, and an AI-native startup named Tano. Until last year, he merged between eight and 20 pull requests per month. Since joining Tano, he ships over 200 pull requests per month, which is approximately a tenfold increase. The essay highlights that old constraints like code reviews disappeared, while new constraints like context switching emerged.

Why it matters
