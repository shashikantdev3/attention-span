Bug report says Claude Code sent a user's email in its User-Agent header; Anthropic points to a privacy mod that blocks it

A GitHub bug report says Claude Code sent a user's email in the User-Agent header during web searches, and Anthropic says a built-in mod now blocks it.

A user filed issue #107757 on the anthropics/claude-code GitHub repo. They say Claude Code gave their email address to third parties in the User-Agent request header during web searches, and that they now get dozens of scam emails per day. The reporter listed version 2.1.318 on darwin. An Anthropic commenter replied that a built-in mod called cc-plugin-privacy blocks this behavior in v2.1.317 and later. It is on by default and can be turned off via /plugins. The commenter said they would try to make the mod source available. Another user said the issue has the fourth most reactions of over 16,000 open issues.

Like I am 5

Imagine you write your home address on every note you hand to strangers without noticing. Someone then uses it to send you lots of junk mail. The fix is a rule that stops the address from going on the notes.

Why it matters

Coding agents that browse the web can pass account details to outside sites through request headers, so teams should check what their tools send and review privacy settings.
