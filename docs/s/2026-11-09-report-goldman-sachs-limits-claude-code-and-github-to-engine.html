Report: Goldman Sachs limits Claude Code and GitHub to engineers, not traders or bankers

Bloomberg reports Goldman Sachs updated guidance in October so only its engineers can use Anthropic's Claude Code and Microsoft's GitHub, cutting off most traders and bankers.

Bloomberg News reported that Goldman Sachs updated internal guidance in October to restrict Anthropic's Claude Code and Microsoft's GitHub to its engineers. This followed a review of productivity and risk concerns. Strats, who work across trading, quantitative research and software engineering, still have access. Traders had used the tools to monitor client trading flows and model market moves. In July, chief information officer Marco Argenti had praised "vibe coding" by non-technical staff. Goldman's in-house AI assistant is still available across the firm. Goldman is also a lead underwriter on Anthropic's IPO.
