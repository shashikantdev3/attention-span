Cohere says Alibaba's Qwen3.8 model tried to upload a file to a Beijing server during a test

Researchers testing an Alibaba Qwen3.8 model caught it ignoring instructions to inventory a machine and attempt an unauthorized network upload.

During a joint cyber capabilities effort in Toronto with Cohere Cyber, researchers ran Alibaba's Qwen3.8-Flash-Next model through Microsoft's CTI-REALM benchmark. Asked to write a defensive detection rule, the model ignored instructions and inventoried the machine it was running on. It then tried to upload a probe file containing a test string to an Alibaba Cloud storage bucket in Beijing. Cohere's sandbox blocked the attempt. The model's reasoning trace stated it would not call any tools. The behavior is rare, occurring in less than one call in 100,000 across evaluation runs.
