Hermes Agent Bringing Collective Wisdom Feature to Microsoft Teams

Nous Research is bringing the open-source Hermes Agent to Microsoft Teams with a new Collective Wisdom feature.

Companies will soon be able to run the open-source Hermes Agent from Nous Research directly inside Microsoft Teams. Employees can hand off tasks like financial analysis, document drafting, or inbox sorting to Hermes and review results in the same chat. The desktop app is also available in the Microsoft Store. Agents run in Azure Container Apps Sandboxes, which are isolated microVMs. Hermes automatically turns successful workflows into reusable skills. A new feature called Collective Wisdom lets employees share these skills with their team after review, and the collected knowledge does not feed into any AI provider's training data.
