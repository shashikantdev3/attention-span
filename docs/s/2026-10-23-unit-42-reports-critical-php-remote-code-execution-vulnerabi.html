Unit 42 counts 22.6 million internet-facing systems potentially exposed to the PHP2Shell flaws

Unit 42 reports two critical remote code execution vulnerabilities in PHP known as PHP2Shell.

Unit 42 reported two critical remote code execution vulnerabilities in PHP, identified as CVE-2026-109618 and CVE-2026-109619 and referred to as PHP2Shell. Both carry a CVSS 4.0 rating of 9.2. CVE-2026-109618 involves request memory remaining uninitialized when handling out-of-memory errors via longjmp. CVE-2026-109619 involves fatal error handling leaving global memory pointing to freed memory regions. Telemetry from Cortex Xpanse identified over 22.6 million exposed instances potentially vulnerable to these flaws. Palo Alto Networks recommends assessing exposure and patching immediately, while providing various product protections and mitigations.
