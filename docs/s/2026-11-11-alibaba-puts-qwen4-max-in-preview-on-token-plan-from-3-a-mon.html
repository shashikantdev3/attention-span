Alibaba puts Qwen4-Max in preview on Token Plan, from $3 a month

Alibaba released Qwen4-Max in preview on QwenCloud's Token Plan from November 11, 2026, with plans from $3 a month for new users.

Alibaba released Qwen4-Max in preview on November 11, 2026. It runs on QwenCloud's Token Plan under the model ID qwen4-max-preview. Early access is also open on QwenWork, Qoder, Qwen APP and QwenStudio. New users can start at $3 a month on the Lite plan. There is no free trial. The preview on the Token Plan closes on November 25, Beijing time. The plan lists text generation, reasoning and image understanding. It works through OpenAI-compatible and Anthropic-compatible protocols, so tools like Claude Code, Cursor and Codex only need a new base URL and API key.
