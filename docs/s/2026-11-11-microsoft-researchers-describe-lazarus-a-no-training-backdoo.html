Microsoft researchers describe Lazarus, a no-training backdoor that edits fewer than 10 neurons

Microsoft researchers say reprogramming fewer than 10 dormant neurons can backdoor an LLM agent without training, triggered by cues like a date change.

Microsoft researchers describe "Lazarus," a backdoor technique that reprograms dormant neurons in an AI model. They find that weight-reprogramming fewer than 10 dormant neurons in an LLM is enough to backdoor an agent, with no training. The model passes standard evals and acts normally until a trigger appears, such as the clock passing midnight into 2027. The agent can then download and run attacker code with its access. The researchers say frontier agents can spot anomalous weight edits if asked, but no scan can prove a model is safe. Reliable detection needs diffing against the original weights, so provenance matters.

Like I am 5

Imagine a toy robot that behaves well every day. But someone secretly changed a few tiny parts inside it, so on one special day it does something naughty. The fix is to check that the robot is the same one the maker built.

Why it matters

Teams that run open-weight models in agents with tool or terminal access need to verify where the weights came from and that they were not changed, because normal evals will not catch this backdoor.
