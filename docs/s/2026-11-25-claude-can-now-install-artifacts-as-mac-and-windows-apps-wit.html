Claude can now install artifacts as Mac and Windows apps with their own icons and windows

Anthropic's 'Install as app' beta turns a Claude artifact into a desktop app that can ask for notifications, shortcuts or even full computer access.

Anthropic is rolling out a beta feature called 'Install as app' in Claude for Mac and Windows that turns an artifact into a standalone desktop app. Installed apps get their own icon and window, can be shared, and must ask before they interact with the computer. Anthropic describes three permission levels: browser-like defaults, app permissions such as notifications and global shortcuts, and full computer access, which is limited to apps made by the user or, on Team and Enterprise, by their organization. Anthropic says it does not review apps before people install them, that requests an app makes to Claude count toward plan usage limits, and that apps need the user to be online and signed in. The feature is on by default for Team plans and off on Enterprise until an owner enables it, and it is not offered to HIPAA-ready organizations or hybrid deployments. SiliconANGLE reports that Anthropic showed internal examples including an image editor, a file manager and a terminal.

Like I am 5

If you ask Claude to make you a little tool, you can now keep it on your computer like a normal app, with its own icon you can click.

Why it matters

It lets people ship AI-generated software straight to the desktop without an app store, which makes the permission model and the lack of review the parts to watch.
