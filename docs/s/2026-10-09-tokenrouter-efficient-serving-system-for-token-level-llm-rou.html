TokenRouter: Efficient Serving System for Token-Level LLM Routing

TokenRouter is a new serving system designed to efficiently handle token-level LLM routing in inference work.

Large language model routing distributes inference work across different models. Coarse-grained routing at the session or query level is common in production systems, but token-level routing offers efficiency and quality gains. Current systems face challenges like step desynchronization and batch admission delays under token-level routing. Researchers designed TokenRouter to solve these challenges. TokenRouter uses request-centric programming and model-centric execution. It launches a subserver for each LLM and dispatches requests asynchronously. Each subserver uses a delayed-batching scheduler. TokenRouter achieves 2.01-64.15x higher decoding throughput than existing systems across diverse routing algorithms, workloads, and model pairs.
