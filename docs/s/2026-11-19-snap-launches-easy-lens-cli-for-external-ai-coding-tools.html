Snap Launches Easy Lens CLI for External AI Coding Tools

Snap launched the Easy Lens CLI on Mac, Windows, and Linux, enabling developers to build AR Lenses using external AI coding tools.

Snapchat announced on Wednesday that it is giving Lens creators the ability to build Lenses using AI coding assistants they already use. These tools include Claude Code, Cursor, and Codex.
