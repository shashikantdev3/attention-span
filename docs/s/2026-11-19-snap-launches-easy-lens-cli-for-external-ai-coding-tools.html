Snap launches Easy Lens CLI so developers can build Lenses with Claude Code, Codex or Cursor

Snap released a free command line version of Easy Lens that lets developers build Snapchat AR Lenses from the AI coding assistants they already use.

Snap announced Easy Lens CLI, which brings its Easy Lens creation tool to the command line so developers can build Snapchat Lenses with AI coding assistants such as Claude Code, Codex and Cursor. It runs on Mac, Windows and Linux and is free to use with a Snapchat account, Snap says. According to Snap, it comes with more than 100 AR building blocks and more than 50 AI asset generators. Lenses made with it can earn money through Lens+ Payouts, and TechCrunch notes Snap paid $1.8 million to Lens+ creators last month.
