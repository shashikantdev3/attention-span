Microsoft Fabric Releases November 2026 On-Premises Data Gateway

Microsoft released version 3000.342 of the on-premises data gateway, improving security, performance, reliability, and diagnostics.

Microsoft released version 3000.342 of the on-premises data gateway. The update continues connectivity support between on-premises data sources and Microsoft Fabric services. It improves security, performance, reliability, and diagnostics. Key updates include better Oracle DirectQuery support, expanded diagnostics in the setup application, and compatibility updates for the November 2026 release of Power BI Desktop. The release also fixes authentication issues by retaining service principal token refresh metadata across gateway operations. Additionally, it improves duplicate packet acknowledgment handling and optimizes memory management.
