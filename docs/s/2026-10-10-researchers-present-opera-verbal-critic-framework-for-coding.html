Researchers Present Opera Verbal Critic Framework for Coding Agents

Opera is a verbal critic framework that treats corrections as persistent notes to improve long-horizon coding agents.

Long-horizon coding agents need timely corrections, but feedback often misjudges work or misses underlying problems. Researchers present Opera, a verbal critic framework that treats each correction as a persistent note until the diagnosed problem is resolved. Opera decides when to review through periodic and event-driven triggers, diagnoses issues with typed operators, audits feedback against visible evidence, and tracks subsequent actions. As a test-time critic, Opera improves resolve rates on Terminal-Bench 2.1, a SWE-Bench Pro subset, and DeepSWE v1.1. Opera-guided rollouts also provide on-policy training data to fine-tune Qwen3.5-9B.
