Amazon Announces Web Search API on Amazon Bedrock AgentCore

AWS announced the Web Search API on Amazon Bedrock AgentCore, allowing custom code to search the web with a single API call.

Amazon introduced the Web Search API on Amazon Bedrock AgentCore. This new API lets developer code search the web using a single call through AWS SDKs or the AWS Command Line Interface. It returns ranked results from an Amazon-operated web index with text extracts, page titles, URLs, and publication times when available. Requests are signed with AWS Signature Version 4 credentials. It serves non-agent use cases, custom orchestration frameworks, and applications requiring real-time web results without setting up a full AgentCore Gateway stack.
