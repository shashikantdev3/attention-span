OpenAI Releases Official Command-Line Tool for the REST API

OpenAI released an official command-line tool to call the OpenAI REST API directly from terminals or shell scripts.

OpenAI released an official command-line tool, OpenAI CLI, designed to call the OpenAI REST API directly from terminals or shell scripts. Users can generate images, upload files, submit batches, and inspect API results without writing an application. The tool supports prebuilt binary downloads for macOS, Linux, and Windows, Homebrew installation, and Go installation requiring Go 1.26 or later. It features update checks, setup guides for API keys, admin endpoints, output formatting options including JSON and YAML, and shell shortcuts.

Like I am 5

It is like a remote control with buttons for your computer terminal that lets you talk straight to OpenAI without building a whole app first.

Why it matters

Interacting with models, managing files, and running batch requests directly from shell scripts becomes possible without writing custom applications.
