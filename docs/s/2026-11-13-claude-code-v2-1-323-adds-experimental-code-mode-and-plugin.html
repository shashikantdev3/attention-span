Claude Code v2.1.323 adds experimental Code Mode and plugin version limits

Claude Code v2.1.323 adds Code Mode, where Claude writes JavaScript to call its tools, plus plugin version checks and many sign-in and stability fixes.

Anthropic released Claude Code v2.1.323. It adds Code Mode, an experimental opt-in in which Claude writes JavaScript to call its tools. Organizations can turn it off. Plugins can now set engines["claude-code"] in plugin.json, and plugins outside the stated version range are not installed, updated or loaded. The claude plugin validate command now type checks a plugin's TypeScript hooks module. Hooks that run long in claude -p and SDK sessions send a progress heartbeat every 30 seconds. The release also fixes many sign-in problems for background sessions, a memory spike after a very large file change, and /compact summarizing away an unanswered message.

Like I am 5

Imagine a helper who used to ask for one tool at a time. Now, in a test mode, the helper can write a short to-do list first and then use many tools from that list.

Why it matters

Plugin authors can now pin the Claude Code versions they support, and teams get an opt-in test of Code Mode with an organization-level off switch, plus steadier long-running hooks and background sessions.
