AI Companies Offer Formal Verification to Combat Low-Quality Code

Software engineers are using formal verification systems with mathematical proofs and logic to avoid low-quality AI-generated code.

Low-quality output from large language models, known as slop, has become a daily concern for software engineers writing code with AI. To address this, AI companies like Harmonic, Theorem, Axiom Math, and a new entrant called &Truth are offering formal verification systems. These systems use mathematical proofs and logic to verify the correctness of software or hardware. Many of these tools build on Lean, an open-source programming language and proof assistant that checks mathematics and helps ensure code satisfies stated requirements.
