Researchers Introduce 3DCodeVerse for Editable 3D Content Generation

Researchers introduced 3DCodeVerse, an ecosystem enabling coding agents to create editable and verifiable 3D content at scale.

Researchers introduced 3DCodeVerse, an ecosystem that enables coding agents to create editable and verifiable 3D content at scale. The ecosystem includes 3DCodeVerse-2M, a large-scale curated dataset of standalone 3D executable code built from open-source data and generated programs. It also features the 3DCodeVerse Harness, a multi-agent directed acyclic graph framework that evaluates and revises generated programs using execution checks, spatial measurements, and visual feedback without human intervention during generation. Experiments show that fine-tuning on the dataset improves open-source model capabilities, and the harness achieves a 90% win rate against Claude Design in pairwise human evaluations.
