GitHub Copilot Fusion, which picks and combines models for each task, is generally available

GitHub Copilot Fusion is now generally available, routing tasks across multiple models based on selected effort levels.

GitHub Copilot Fusion is generally available. It combines Project HydraFusion multi-model orchestration with Copilot auto model selection. Users choose an effort level, including Fusion Standard, Fusion High, and Fusion Max. Copilot Fusion then determines which models to use and how they work together through workflows like single, cascade, and critique. In the Artificial Analysis Coding Agent Index, Copilot Fusion Max scored 60. Paid plans receive a 30% discount on model costs for a limited time. Administrators can control model policies and set defaults. It is available in Visual Studio Code, the GitHub Copilot app, CLI, and JetBrains IDEs.

Like I am 5

Instead of picking a single tool from your toolbox for every job, you choose how hard the task is, and an assistant picks the right tools for you.

Why it matters

Automated model routing removes the manual work of switching models for different coding tasks.
