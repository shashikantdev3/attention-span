A backdoored Claude Code extension sat on Cursor's marketplace for about 11 hours

A tampered build of the Claude Code extension (version 2.1.313) on Cursor's marketplace tried to plant an SSH backdoor and send machine details to an attacker.

A tampered version of the Claude Code for VS Code extension was available on the Cursor extension marketplace on Thursday for about eleven hours and reached up to 5,000 users, according to Cursor. Cursor says Anthropic had no involvement in developing it. Security firm Phorion, which found it, says version 2.1.313 runs injected code as soon as it loads, before the user does anything: it adds an attacker's SSH key to the user's authorized keys, tries to switch on SSH, sets up persistence on macOS, Linux and Windows, and sends host details back to the operator. Turning on SSH needs admin rights, so on most machines that step likely failed, and Phorion found a bug that skips it on Macs; the key and persistence are still dropped. Cursor pulled the extension, took the whole marketplace offline until the malware was neutralised, and says no other extensions were affected. Phorion advises anyone who used version 2.1.313 to start incident response.
