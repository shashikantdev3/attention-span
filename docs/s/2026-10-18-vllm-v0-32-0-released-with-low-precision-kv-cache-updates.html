vLLM v0.32.0 released with low-precision KV cache updates

vLLM version 0.32.0 brings low-precision KV cache support, Model Runner V2 updates, and new structured parsers.

The vLLM project released version 0.32.0, featuring 814 commits from 363 contributors. The release introduces the POST /v1/systemone endpoint for structured state decisions and a generic hf tool and reasoning parser. Low-precision KV cache updates include NVFP4 KV cache on various architectures and an FP8 KV cache default for GLM-5.x on SM100. Model Runner V2 becomes the default on ROCm and adds features like a GPU n-gram speculator and Elastic EP. The update also improves startup and serving speeds, adds new model support including EmbeddingGemma 2 and MiniCPM-V 4.7, and includes security fixes and breaking changes.
