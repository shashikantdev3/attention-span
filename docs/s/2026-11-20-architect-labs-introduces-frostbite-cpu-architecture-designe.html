Architect Labs Introduces Frostbite CPU Architecture Designed by AI

Architect Labs introduces Frostbite, a new general-purpose CPU architecture and instruction set discovered, designed, and verified end-to-end by AI systems.

Architect Labs introduced Frostbite, a general-purpose CPU with a new instruction set built from the ground up and discovered, designed, and verified end-to-end by AI systems. The AI autonomously iterated over the compiler, ISA, architecture, microarchitecture, RTL, verification, and final GDS. Frostbite exploits the properties of interaction nets, where every step is local, every dependency is explicit, and every value has exactly one owner. On a set of 25 workloads, Frostbite achieved a 4.59x performance-per-watt multiple compared to a modern, silicon-proven superscalar CPU core.
