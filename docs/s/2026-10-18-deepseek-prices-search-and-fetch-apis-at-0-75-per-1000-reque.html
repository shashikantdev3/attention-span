DeepSeek Prices Search and Fetch APIs at $0.75 per 1000 Requests

DeepSeek introduced Search and Fetch APIs priced at $0.75 per 1000 successful requests, giving agents and RAG applications access to live web content.

DeepSeek has released Search and Fetch raw JSON APIs that give agents and retrieval-augmented generation applications access to live web content. The Search API finds web pages using an in-house search engine, while the Fetch API retrieves a single web page and returns its content as Markdown. Both APIs use bearer authentication and cost $0.75 per 1000 successful requests. Billing applies only when requests return HTTP 200 and produce results. Server-side tool calls made through DeepSeek Harness, Claude Code, or Codex are currently free of charge, with per-request billing starting at 00:00 Beijing time on November 1, 2026. The APIs feature account-level and domain-level rate limits.
