Serving GLM-5.3 Across Two NVIDIA DGX Stations With vLLM

A 753 billion parameter model is served locally across two NVIDIA DGX Stations using vLLM and tensor parallelism.

The GLM-5.3 NVFP4 mixture-of-experts model has 753 billion parameters and 40 billion activated per token. Because its checkpoint requires about 464 GB of GPU memory, it exceeds the capacity of a single GB300 GPU. To run it locally, two NVIDIA DGX Stations are connected over ConnectX-8 RDMA and use tensor parallelism with TP=2. vLLM launches a distributed service across both stations, enabling multi-token prediction, FP8 KV-cache storage, and prefix caching. AIPerf benchmarks show output throughput peaking at 607.8 tokens per second at concurrency 16 before falling to 385.0 tokens per second at concurrency 32.

When a very large computer model is too big to fit inside a single computer, you can split its brain across two linked computers so they can work on it together.

Why it matters

Running frontier-scale models locally becomes possible by distributing weights and computation across multiple connected hardware stations.
