GitHub Copilot Brings On-Device AI Coding to Windows PCs

GitHub Copilot will coordinate local and cloud intelligence on new Windows PCs using a local version of MAI Code 1.1 Flash.

GitHub Copilot is introducing on-device AI coding capabilities to Windows PCs. Coming by the end of the month, Copilot will automatically determine when tasks require on-device intelligence or cloud-scale models. Microsoft AI developed a local version of MAI Code 1.1 Flash, a coding-optimized mixture-of-experts model with 137 billion total and 6.8 billion active parameters. The system runs on hardware like the Surface Laptop Ultra powered by NVIDIA RTX Spark, utilizing quantization and speculative decoding to reduce the model footprint while maintaining task completion and tool-use quality.
