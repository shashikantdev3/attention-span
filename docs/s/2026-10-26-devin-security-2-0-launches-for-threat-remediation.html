Cognition launches Devin Security 2.0 for finding and fixing vulnerabilities

Devin Security 2.0 combines frontier model scanning, environment-grounded prioritization, and autonomous remediation into a single workflow.

Devin Security 2.0 connects discovery, prioritization, and remediation in one workflow. It uses frontier cyber models, including Claude Mythos, through an architecture called Agentic MapReduce to scale security investigations. The system maps repositories for routes, authorization boundaries, and data access. Findings are checked against a threat model, grouped, and investigated in parallel. Selected findings can be assigned to Devin for remediation sessions. Devin uses a virtual machine to reproduce the issue, implement a fix, test the result, and open a pull request with the investigation and test results.
