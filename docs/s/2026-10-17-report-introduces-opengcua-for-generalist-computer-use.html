Report Introduces OpenGCUA for Generalist Computer Use

Researchers introduced OpenGCUA, an open stack project for generalist computer-use agents, to improve task scores and reduce steps on OSWorld-v2.

Researchers introduced OpenGCUA, an ongoing project to develop and open the full stack for generalist computer-use agents with the community. Frontier implementations of computer-use systems remain largely closed. The first release features code execution, allowing intermediate results to determine subsequent operations. It also proposes harness-to-model decision transfer, moving selected observations and task-state decisions from fixed harness rules to the model. On OSWorld-v2, the full configuration improves task scores across eight evaluated models, including GPT-6 Astra and Claude Opus 5. It raises the mean partial score by +19.6 points and reduces reported steps per task by an average of 53.0 percent relative to batched GUI-only execution.
