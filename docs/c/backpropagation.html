Concept, Math and neurons

What is Backpropagation?

An efficient way to compute how much each weight in a multi-layer network contributed to the error, using the chain rule.

Like I am 5

After a team loses, working backwards to find how much each player was to blame, so each one practises the right thing.

Evolved from: Gradient descent, Perceptron

Led to: Convolutional neural network (CNN), Deep learning, Deep learning framework, Recurrent neural network (RNN)

In history

  • 1986-10-09: Backpropagation popularised for training multi-layer networks. A way to share the blame for an error across every layer, so deep networks can learn.
  • 1989-12: LeCun applies convolutional networks to handwritten digits. A network with shared filters reads handwritten zip codes for the US postal service.
  • 2024-10-08: Nobel Prize in Physics to Hopfield and Hinton. Awarded for foundational discoveries that enable machine learning with artificial neural networks.
