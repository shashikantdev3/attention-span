What is Multimodal model?

A model that understands or produces more than one kind of data, such as text, images and audio.

Like I am 5

A friend who can read, look at photos and listen, all at once.

Evolved from: Large language model (LLM), Vision transformer (ViT)

Led to: Computer use, Physical AI

In history

  • 2021-01-05: DALL-E generates images from text. Type a description and a model draws it.
  • 2021-02-26: CLIP connects images and text. Trained on image and caption pairs, it can classify images by any text label.
  • 2023-03-14: GPT-4. A large step in reasoning, passing many professional exams, with image input.
  • 2023-12-06: Gemini: Google's natively multimodal model. One model family trained from the start on text, images, audio and video.
  • 2024-03-04: Claude 3 family. Haiku, Sonnet and Opus: three sizes, with Opus leading several benchmarks.
  • 2024-05-13: GPT-4o: real-time voice and vision. One model handles text, audio and images, answering speech in about human response time.
