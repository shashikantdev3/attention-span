Concept, Building with AI

What is Tool use (function calling)?

Also called function calling

A model outputting structured calls to external functions or APIs, then using the results.

Like I am 5

A smart kid who knows when to grab a calculator or a dictionary instead of guessing.

Evolved from: Large language model (LLM)

Led to: AI agent, Model Context Protocol (MCP), ReAct pattern, Structured outputs

In history

  • 2022-10-06: ReAct: reasoning and acting. The model thinks, takes an action like a search, reads the result, and thinks again.
  • 2023-02-09: Toolformer teaches models to use tools. A model learns by itself when to call a calculator, search or calendar API.
  • 2024-11-25: The Model Context Protocol (MCP). One open standard for plugging tools and data into any AI app, like USB-C for AI.
