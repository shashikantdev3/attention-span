What is Agent sandbox?

Also called agent containment

An isolated environment where an AI agent can run code and use tools without being able to touch the rest of the computer or network. Microsoft's Execution Containers (MXC) are one example.

Like I am 5

A sandpit with walls: the agent can build and break things inside it, but nothing outside gets hurt.
