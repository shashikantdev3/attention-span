What is Sliding-window attention?

Also called local attention

An attention pattern where each token looks only at a fixed number of nearby tokens instead of the whole input, so memory and compute stay flat as the text gets longer.

Like I am 5

Reading a long book while keeping only the last few pages open in front of you.
