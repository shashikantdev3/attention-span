What is Large language model (LLM)?

Also called LLM

A transformer language model with billions of parameters trained on huge text collections, able to follow instructions and write.

Like I am 5

A giant autocomplete that read most of the internet, so its guesses become surprisingly useful answers.

Evolved from: Language model, Transformer, Pre-training

Led to: AI coding assistant, Copilot (Microsoft), Distillation, Foundation model, Hallucination, In-context learning, Multimodal model, Natural language to query, Open-weight model, Retrieval-augmented generation (RAG), Reasoning model, Scaling laws, Small language model (SLM), Speculative decoding, Tool use (function calling)

In history

  • 2018-06-11: GPT-1: generative pre-training. Pre-train a transformer on lots of text, then fine-tune it for each task.
  • 2019-02-14: GPT-2 and staged release. A bigger GPT writes convincing paragraphs, and OpenAI releases it in stages over misuse concerns.
  • 2020-05-28: GPT-3 and in-context learning. A 175-billion-parameter model learns new tasks from a few examples in the prompt.
  • 2021-06-29: GitHub Copilot previews AI pair programming. An AI that suggests whole lines and functions inside your editor.
  • 2022-04-05: PaLM scales to 540 billion parameters. A very large Google model shows breakthrough reasoning with chain-of-thought.
  • 2022-11-30: ChatGPT launches. A free chat interface to a GPT-3.5 model becomes the fastest growing consumer app of its time.
  • 2023-01-23: Microsoft extends its OpenAI partnership. A multi-year, multi-billion-dollar investment, with Azure as OpenAI's cloud.
  • 2023-02-24: LLaMA starts the open-weight wave. Meta releases research models whose 13B version beats GPT-3 on many benchmarks.
  • 2023-03-14: Anthropic launches Claude. Anthropic's assistant opens to businesses, trained with Constitutional AI.
  • 2023-03-14: GPT-4. A large step in reasoning, passing many professional exams, with image input.
  • 2023-03-16: Microsoft 365 Copilot is announced. GPT-4 grounded in your emails, documents and meetings, inside Word, Excel and Teams.
  • 2023-12-06: Gemini: Google's natively multimodal model. One model family trained from the start on text, images, audio and video.
  • 2024-03-04: Claude 3 family. Haiku, Sonnet and Opus: three sizes, with Opus leading several benchmarks.
  • 2024-06-20: Claude 3.5 Sonnet and Artifacts. A mid-size model that beats the previous top model, plus a side panel for live outputs.
  • 2025-08-07: GPT-5. One system that decides when to answer fast and when to think longer.
