What is Transformer?

A network built from attention layers that processes all tokens in parallel. The architecture behind modern LLMs.

Like I am 5

A classroom where every word can talk to every other word at once, instead of passing notes down the row.

Evolved from: Attention, Residual connection

Led to: Context window, Large language model (LLM), Mixture of experts (MoE), Sliding-window attention, Vision transformer (ViT)

In history

  • 2017-06-12: Attention Is All You Need: the transformer. A network built only from attention, which trains in parallel and scales well.
  • 2018-10-11: BERT reads in both directions. A transformer trained to fill in masked words tops most language benchmarks.
  • 2020-10-22: Vision transformer (ViT). Cut an image into patches, treat them like words, and a plain transformer sees well.
