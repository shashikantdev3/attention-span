Concept, Building with AI

What is AI coding assistant?

Tools that suggest, write or edit code with LLMs, from autocomplete to autonomous coding agents.

Like I am 5

A helper sitting next to you who finishes your sentences, but in code.

Evolved from: Large language model (LLM)

Led to: Vibe coding

In history

  • 2021-06-29: GitHub Copilot previews AI pair programming. An AI that suggests whole lines and functions inside your editor.
  • 2024-06-20: Claude 3.5 Sonnet and Artifacts. A mid-size model that beats the previous top model, plus a side panel for live outputs.
  • 2025-02-02: Karpathy coins 'vibe coding'. Building software by describing what you want and accepting what the AI writes.
  • 2025-02-24: Claude 3.7 Sonnet and Claude Code. A hybrid model with optional extended thinking, plus an agent that codes in your terminal.
  • 2025-05-22: Claude 4: Opus 4 and Sonnet 4. Models built for long-running coding and agent tasks.
