What is Reinforcement learning?

Also called RL

Learning by trial and error from rewards and penalties.

Like I am 5

Like training a puppy with treats: good moves get a treat, so it does them more.

Evolved from: Machine learning

Led to: Q-learning, Reasoning model, RLHF

In history

  • 1959-07: Arthur Samuel's checkers program learns to play. A program improves at checkers by playing itself, and the phrase 'machine learning' enters use.
  • 1992-05: Q-learning gets its convergence proof. An agent learns the value of each action by trial and error, with no model of the world.
  • 1995-03: TD-Gammon reaches expert backgammon by self-play. A neural network teaches itself backgammon by playing against itself.
  • 2013-12-19: Deep Q-networks learn Atari games from pixels. One network learns to play several Atari games from the screen and the score alone.
  • 2016-01-27: AlphaGo masters Go. Neural networks plus tree search beat a Go professional, then world champion Lee Sedol in March.
  • 2017-07-20: Proximal policy optimisation (PPO). A stable, simple reinforcement learning algorithm that takes careful small steps.
