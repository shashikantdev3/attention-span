What is Speculative decoding?

A way to speed up text generation: a small, fast model drafts the next few tokens and the large model checks them all in one pass, keeping the ones it agrees with.

Like I am 5

A quick helper guesses the next few words and the expert only says yes or no, which is faster than the expert writing every word.

Evolved from: Inference, Large language model (LLM)
