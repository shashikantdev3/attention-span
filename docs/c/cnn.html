What is Convolutional neural network (CNN)?

Also called ConvNet

A network that slides small learned filters across an image, so the same feature detector works everywhere.

Like I am 5

Looking at a picture through a small window and moving it around, checking each spot for edges and shapes.

Evolved from: Backpropagation, Perceptron

Led to: Residual connection, Vision transformer (ViT)

In history

  • 1989-12: LeCun applies convolutional networks to handwritten digits. A network with shared filters reads handwritten zip codes for the US postal service.
  • 1998-11: LeNet-5 and gradient-based document recognition. The classic convolutional network design, used to read cheques at scale.
  • 2012-12: AlexNet wins ImageNet by a wide margin. A deep convolutional network trained on two GPUs cuts the ImageNet error rate sharply.
  • 2015-12-10: ResNet: very deep networks with skip connections. Shortcut connections let networks go 150 layers deep and still train.
