What is Embedding?

A vector of numbers representing any item (text, image, product) so that similar items sit close together.

Like I am 5

A map address for anything, so similar things end up in the same neighbourhood.

Led to: Retrieval-augmented generation (RAG), Vector database

In history

  • 2020-05-22: Retrieval-augmented generation (RAG). Look up relevant documents first, then generate the answer from them.
  • 2021-02-26: CLIP connects images and text. Trained on image and caption pairs, it can classify images by any text label.
