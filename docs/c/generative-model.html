What is Generative model?

A model that learns what the data looks like so it can produce new examples of it.

Like I am 5

Someone who has seen so many cats they can draw a brand new one.

Evolved from: Discriminative model

Led to: Diffusion model, Generative adversarial network (GAN), Variational autoencoder (VAE), World model

In history

  • 2013-12-20: Variational autoencoders. A network that learns a smooth space of possibilities and can sample new data from it.
  • 2014-06-10: Generative adversarial networks. Two networks compete: one forges images, the other spots forgeries, and both get better.
  • 2020-06-19: Denoising diffusion models. Learn to remove noise step by step, then generate images from pure noise.
  • 2021-01-05: DALL-E generates images from text. Type a description and a model draws it.
