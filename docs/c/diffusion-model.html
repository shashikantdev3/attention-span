What is Diffusion model?

A generative model that learns to reverse a noising process, building images from random noise step by step.

Like I am 5

Starting with TV static and cleaning it a little at a time until a picture appears.

Evolved from: Variational autoencoder (VAE), Generative model

Led to: none in this glossary yet

In history

  • 2020-06-19: Denoising diffusion models. Learn to remove noise step by step, then generate images from pure noise.
  • 2022-08-22: Stable Diffusion is released openly. A high-quality image model anyone can run on a home GPU.
