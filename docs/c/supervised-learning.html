Concept, Learning methods

What is Supervised learning?

Learning from examples that come with the right answer (labels), such as photos marked cat or dog.

Like I am 5

Learning with an answer key: practise, check the answer, fix your mistake.

Evolved from: Machine learning

Led to: Self-supervised learning

In history

  • 1958: Rosenblatt's perceptron learns from examples. A machine that adjusts its own weights from labelled examples: the first learning neural network.
  • 1995-09: Support vector machines. A classifier that draws the widest possible margin between classes.
  • 2001-10: Random forests. Many decision trees vote, and the crowd beats any single tree.
