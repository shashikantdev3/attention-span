Concept, Building with AI

What is AI agent?

A system where a model plans and takes multi-step actions with tools toward a goal, with little human input per step.

Like I am 5

Not just answering 'how do I book a train' but actually going and booking it.

Evolved from: ReAct pattern, Tool use (function calling)

Led to: Agent2Agent protocol (A2A), Agent memory, Agent sandbox, Computer use, Personal agent, Vibe coding

In history

  • 2022-10-06: ReAct: reasoning and acting. The model thinks, takes an action like a search, reads the result, and thinks again.
  • 2024-10-22: Claude computer use. A model that looks at the screen, moves the mouse and types like a person.
  • 2024-11-25: The Model Context Protocol (MCP). One open standard for plugging tools and data into any AI app, like USB-C for AI.
  • 2025-02-24: Claude 3.7 Sonnet and Claude Code. A hybrid model with optional extended thinking, plus an agent that codes in your terminal.
  • 2025-04-09: Agent2Agent (A2A) protocol. An open protocol for agents from different vendors to talk to each other.
  • 2025-05-19: Microsoft Build 2025: the open agentic web. Microsoft backs MCP across Windows, GitHub and Azure AI Foundry.
  • 2025-05-22: Claude 4: Opus 4 and Sonnet 4. Models built for long-running coding and agent tasks.
  • 2026-02-15: OpenClaw creator Peter Steinberger joins OpenAI. The developer behind the viral OpenClaw personal agent moves to OpenAI.
